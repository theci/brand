# 예시 시나리오 ⑤ — 저당 젤리로 배우는 **저자본 건강간식 창업**

이 문서는 시나리오 시리즈의 다섯 번째 편이며, 첫 **식품(食品)** 편입니다.
앞선 편들은 화장품·방향제였지만, 이번엔 **먹는 것 — 일반식품(식품위생법)** 입니다.

> **"불량식품처럼 맛있는데 죄책감 없는 저당 젤리를, 자본 거의 없이 시작할 수 있을까?"**

자본이 적은 1인 창업자가 **아이디어 → 규제 검토 → 처방 → 영양성분 → 라벨 → 문구 → 원가 → 출시**까지
이 플랫폼의 **식품 레짐**으로 어떻게 밟는지, 그리고 어디서 돈을 잃는지를 실황으로 보여줍니다.

> 명령은 모두 이 저장소에서 **그대로 실행됩니다**(아래 출력은 실제 실행 결과).
> ⚠️ 규제 수치·영양값·알레르기 목록은 **예시**입니다. 식품은 식품위생법·식품표시광고법 영역이며,
> 최종 판단은 식약처·관할 지자체가 합니다. 출시 전 원문 대조가 필수입니다.

**만들 제품**: 저당 포도 젤리 (일반식품, 30g 스틱) · 목표 초도 5,000개 · 저자본(무재고 지향)

---

## 이 문서에서 배울 것 (저자본 관점)

1. **화장품과 무엇이 다른가** — 식품 레짐(영양성분표·알레르기·소비기한), 그리고 이 도구가 **대체 못 하는 것(미생물·HACCP)**
2. **"건강 주장"의 함정** — 저당은 OK, "혈당·면역·다이어트"라고 하는 순간 **건강기능식품(수백만~수억)** 이 된다
3. **제품력은 숫자로** — 영양성분 계산으로 "저당"을 입증
4. **저자본 최대의 적은 배송비** — 낱개 온라인 판매가 왜 팔수록 손해인지, 그리고 해법
5. **무재고로 시작하는 법** — 즉석판매제조가공·공유주방·크라우드펀딩 선주문

## STEP 0 — 시장의 빈틈: "죄책감 없는 불량식품"

> **"편의점 젤리는 맛있지만 당이 너무 높다. 제로 젤리는 많아졌지만 맛이 밍밍하거나 인공감미료 뒷맛이 강하다."**
> 리뷰를 3주간 읽으며 반복되는 불만을 모았다.

| 가격대/유형 | 고객 불만 | 숨은 니즈 |
|---|---|---|
| 일반 젤리 | "맛있는데 당이 너무 높아 죄책감" | 맛은 그대로, **당류만 낮게** |
| 기존 제로 젤리 | "맛이 없다 / 인공감미료 뒷맛" | **자연스러운 단맛**의 저당 |

> **"빈틈: '진짜 맛있는데 당류는 낮은' 젤리. 감미료를 알룰로스(희소당)로 바꾸면 설탕 맛에 가까우면서 당류를 확 낮출 수 있다."**
> **"단, 저당 젤리 시장도 이미 경쟁이 있다. 그래서 '특정 맛(포도)+식감+로컬/펀딩'으로 좁게 시작한다."**

**➡️ 배울 점:** 신제품은 **불평의 교집합**("맛있다 ↔ 죄책감")에서 나온다. 레드오션이어도 **좁은 진입점**(한 가지 맛·무재고 채널)이 있으면 1인이 비집고 들어갈 수 있다.

## STEP 1 — 규제 먼저: 이건 일반식품인가, 건강기능식품인가? (`advise`)

> **"만들기 전에 확인하자. '저당 젤리'는 무슨 법일까? 혹시 '혈당에 좋다'고 하면 안 되나?"**
> 이 플랫폼의 심장 — **무엇이라 부르느냐가 규제비용을 수백 배 바꾼다.**

먹는(ingest) + 영양/맛(nourish):
```bash

```
```

규제비용 비교
  일반식품(과자·젤리 등) … 등록비 28,000원 · SKU×5 0원 · 총 28,000원 · 14일  ⭐
적합성: OK
```

> **"일반식품이면 영업등록 몇만원이고 SKU 늘려도 추가 규제비용 0원. 화장품이랑 비슷한 저부담 구조다."**

그런데 만약 **"혈당·면역·다이어트"** 를 주장하면?
```bash

```

```
  • 규제비용 3,000,000원이 1인 창업 임계(1,000,000원)를 초과합니다. 사업성을 재검토하세요.
```

> **"헉. '면역력'이라고 한 단어 붙였을 뿐인데 건강기능식품이 되고, 제조업 허가·시설요건(근사 300만, 실제론 훨씬 큼)에 개별인정형은 수억·수년이다."**
> **"결론: 나는 기능성을 표방하지 않는다. '저당·맛있는 젤리'로만 승부한다. 이게 저자본의 생존 전략이다."**

**➡️ 배울 점:** 저자본이라면 **일반식품 라인에 머물러야** 한다. "건강" 단어의 수위가 곧 규제 레짐을 가른다. (STEP 6에서 문구를 실제로 검사한다.)

## STEP 2 — 원료·처방: 알룰로스가 차별점 (`formulas/low-sugar-jelly/v1.yaml`)

> **"차별점(저당)에 돈을 쓴다. 설탕·물엿 대신 알룰로스로 당류를 낮춘다. 나머지는 단순하게."**

```yaml
product: 저당 포도 젤리
slug: low-sugar-jelly
version: 1
regime: food                 # ★ 식품위생법(일반식품)
product_category: 과자류_젤리
product_type: leave_on       # 식품엔 의미 없는 placeholder(코어 필수 필드)
status: 개발중
base_batch_g: 1000
phases:
  - name: A (가열 용해)
    process: 정제수에 알룰로스·사과농축과즙·젤라틴을 넣고 80도로 저어 완전히 용해
    ingredients:
      - { id: purified-water, percent: 54.5 }
      - { id: allulose, percent: 25.0 }         # ← 저당의 핵심(희소당)
      - { id: apple-juice-concentrate, percent: 10.0 }
      - { id: gelatin, percent: 8.0 }           # 식감(겔)
  - name: B (냉각 후 첨가)
    process: 60도 이하로 식힌 뒤 구연산·착향료를 넣고 몰드에 충전, 냉장 응고
    ingredients:
      - { id: citric-acid-food, percent: 2.0 }  # 새콤한 맛
      - { id: grape-flavor-food, percent: 0.5 }
packaging:
  - { id: jelly-pouch-30g, qty_per_unit: 1 }
net_weight_g: 30
```

> **"원료는 전부 `food_grade: true`(식품용 등급)여야 한다. 화장품용 원료를 잘못 쓰면 도구가 error로 잡는다."**
> **"상(phase)은 식품에선 '가열→냉각' 공정 단계다. 향·산은 열에 약하니 60도 이하에서 마지막에 넣는다."**

## STEP 5 — 라벨/규정: 화장품과 완전히 다르다 (식품 레짐)

> ⚠️ **"식품은 `label`(화장품 전성분 전용) 명령을 쓰지 않는다."** 식품 레짐의 검증·표시기준을 쓴다.

```bash

lab = BrandLab.load()
f = next(x for x in lab.formulas if x.slug=='low-sugar-jelly')
r = regime_for(f)
print('레짐:', r.display_name, '/', r.law_name)
for fd in r.validate(f): print('[%s]' % fd.level, fd.message)
print('표시항목:', [it.label for it in r.label_spec(f).items])
"
```

> **"화장품은 '전성분'이 핵심이었는데, 식품은 '영양성분표 + 알레르기 + 소비기한 + 식품유형'이 핵심이다. 완전히 다른 표시 체계."**

## STEP 6 — 문구 검사: "건강 주장"의 선을 넘지 마라 (`lint`, food 도메인)

> **"상세페이지에 '면역력 UP! 다이어트 젤리!'라고 쓰고 싶다. 그런데 STEP 1에서 봤듯 기능성 표방은 건기식 영역이다. 진짜 걸리는지 검사하자."**

문구검사는 **도메인(레짐)** 을 고를 수 있고, `food/ad_terms.yaml`(식품표시광고법)로 검사합니다.
```bash
uv run python -c "
from pathlib import Path
from brandlab.loader import PROJECT_ROOT, load_ad_terms
from brandlab.adcopy import lint
terms = load_ad_terms(Path(PROJECT_ROOT)/'data'/'regulatory'/'food'/'ad_terms.yaml')
r = lint('면역력 높여주는 다이어트 젤리! 혈당 걱정 없이 매일 디톡스', terms)
for x in r.findings: print(x.expression, '(%s/%s)'%(x.category,x.risk), '→', x.suggestion)
"
```
```
면역력 (functional_claim/high) → 일반식품은 기능성 표방 불가 (건기식 인정 필요)
다이어트 (functional_claim/high) → 체중 관련 표현은 건강기능식품 영역 — 일반식품 표방 주의
혈당   (functional_claim/high) → 혈당 관련은 기능성 — 일반식품 사용 불가
디톡스 (unverified_claim/medium) → 체내 정화 등 미검증 표현 주의
```

> **"전부 걸렸다. '면역력·다이어트·혈당'은 일반식품이 못 쓴다. 이걸 그냥 썼으면 식품표시광고법 위반이었다."**
> 대신 쓸 수 있는 표현: "**설탕 대신 알룰로스**", "**당류 100g당 4.6g**", "**새콤달콤 포도맛**" — **사실(성분·수치)** 과 **맛** 은 되고, **기능(건강 효능)** 은 안 된다.

**➡️ 배울 점:** 저자본 식품의 마케팅은 **"기능"이 아니라 "성분·수치·맛"** 으로 한다. 도구가 선을 넘는 표현을 사전에 잡아준다.

✅ **게이트:** functional_claim/drug_claim high가 0건이 될 때까지 수정.

```
목표마진 40% 최소판매가: 13,697원
총 선투입 자본: 1,009,350원 (원료 409,350 + 부자재 600,000)
```

> **"충격. 원가는 202원인데 공헌이익이 −2,144원이다. 왜? **배송비 3,000원** 때문이다."**
> **"2,000원짜리를 낱개로 택배 보내면 배송비가 판매가보다 크다. 40% 마진 최소가가 13,697원 — 젤리 한 스틱을 그 값에 팔 순 없다."**

**이게 저자본 간식 창업의 진짜 벽이다.** 해법은 셋:

| 해법 | 어떻게 | 배송비 구조 |
|---|---|---|
| **묶음 판매** | 10~20스틱을 한 박스로 | 배송비가 20개에 분산 → 개당 150원 |
| **오프라인·즉석판매** | 매장/마켓/플리마켓 직판 | **배송비 0** (즉석판매제조가공업) |
| **크라우드펀딩** | 와디즈 등 묶음 리워드 선주문 | 배송비 묶음화 + **무재고 선주문** |

> **"낱개 온라인은 버린다. '10스틱 박스'를 기본 단위로 잡고, 초기엔 매장·펀딩으로 배송비를 없애거나 묶는다."**
> **"MOQ 병목: 파우치 MOQ 5,000 = 필요 5,000 → 사장 재고 0. 선투입 자본 약 100만원(원료 41만+부자재 60만)."**

**➡️ 배울 점:** 싼 간식일수록 **배송비가 사업을 결정**한다. 도구가 "팔수록 손해"를 미리 알려준다 — **묶음·오프라인·펀딩**으로 배송 구조를 바꿔야 산다.

✅ **게이트:** 실제 판매 단위(묶음)에서 공헌이익이 양(+)인가?

## STEP 8 — 안정성·유통기한, 그리고 도구가 못 하는 것

> **"화장품 안정성 대신, 식품은 '소비기한'과 '미생물 안전'이다."**

```yaml
# experiments/stability/JELLY-001-실온.yaml (개념)
sample_id: JELLY-001
formula_ref: low-sugar-jelly v1
condition: 45C          # 가속 조건(실온 유통기한 추정)
start_date: 2026-08-24
observations: []
```

> **관찰 포인트(식품):** 이수(물 빠짐)·곰팡이·색/냄새 변화·식감 변화.
> ⚠️ **이 도구가 대체 못 하는 것:** **미생물 검사(세균수·대장균)·식중독 안전·HACCP**. 이건 처방이 아니라 **시설·공정** 문제다.
> **저당 젤리는 수분활성도(Aw)가 높아 미생물 위험이 있다.** 반드시 **자가품질검사(위탁)** 로 미생물·유통기한을 확인해야 한다. 도구는 "언제 검사할지" 추적만 돕는다.

✅ **게이트:** 실온/가속 관찰 + **위탁 미생물·유통기한 시험 합격**이라야 출시.

## STEP 9 — 저자본 출시: 무재고로 시작하는 법

> **"돈이 없으니 공장에 5,000개부터 찍지 않는다. 재고를 짊어지지 않는 순서로 간다."**

1. **즉석판매제조가공업으로 소규모 시작** — 공유주방(위생교육+영업신고)에서 소량 제조, **마켓·플리마켓·매장 직판**. 배송비 0, 무재고, 반응 검증.
2. **크라우드펀딩(와디즈 등) 선주문** — "10스틱 박스"를 리워드로. **목표액 달성 후 생산** → 재고 리스크 0에서 초도 물량 확보.
3. **반응 검증 후 OEM 양산**(STEP 10) — 재구매·펀딩 성적이 좋을 때만 규모를 키운다.

> **"헤트라스 편에서 배운 것과 같다: 규모(양산)는 제품력이 검증된 뒤에 거는 베팅이다. 순서를 뒤집으면 창고에 젤리가 쌓인다."**

## STEP 10 — 식품 OEM 양산: 특화 주의점

공통 절차(NDA·견적·계약·검수)는 [`예시_시나리오.md`](예시_시나리오.md) STEP 10을 따르고, **식품에서만 다른 점**:

```
식품 OEM에 반드시 확인:
□ HACCP 인증 시설인가 (식품 안전의 전제)
□ 품목제조보고를 공장이 대행하나, 내가 하나
□ 자가품질위탁검사(미생물·이물·영양성분) 주체·주기
□ 소비기한 설정 근거(가속시험·실측) 자료 제공
□ 알레르기 교차오염 관리(같은 라인 우유·대두 등) → '이 제품은 ~를 사용한 시설에서 제조' 표시
□ 최소 생산량(식품 OEM은 MOQ가 큰 편) → 초도 자본과 대조
```

> **"영양성분표는 '계산값(STEP 3)'으로 시작하되, 출시 라벨은 **공인기관 분석값**으로 확정해야 한다. 계산과 실측이 다를 수 있다."**

✅ **STEP 10 게이트:** HACCP 시설 · 자가품질검사 · 소비기한 근거 · 알레르기 관리 · 품목제조보고 확인.
