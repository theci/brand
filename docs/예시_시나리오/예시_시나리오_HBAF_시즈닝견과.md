# 예시 시나리오 ⑦ — "HBAF(바프)"에게 배우는 **시즈닝 견과 개발·테스트**

이 문서는 시리즈 일곱 번째 편으로, **시즈닝 견과류** 카테고리의 기획·개발·테스트를 다룹니다.
허니버터아몬드로 시작해 수십 종 플레이버로 확장한 **HBAF(바프)** 에 착안한 **학습용 재구성**입니다.

> ⚠️ **중요 — 학습용 재구성입니다.**
> 실제 HBAF의 원료 레시피·수치는 공개돼 있지 않습니다. 이 문서의 처방·DOE 점수·원가는
> "시즈닝 견과 개발에서 일반적으로 부딪히는 문제"를 바탕으로 **가정한 것**이며 실제 브랜드와 무관합니다.
> 배울 것은 **레시피가 아니라 개발·테스트 과정과 SKU 전략**입니다. 규제·영양값도 예시입니다.

**만들 제품**: 허니버터 시즈닝 아몬드 (일반식품·견과류가공품, 30g 봉지) · 상온 유통

---

## 이 문서에서 배울 것

1. **시즈닝 견과의 3대 개발 변수** — 부착률(코팅) / 바삭함(로스팅) / 산패(견과 지방 산화)
2. **HBAF 성공의 핵심 = 플레이버 SKU 확장** — 왜 매달 새 맛을 낼 수 있나(규제·개발비 관점)
3. **견과의 숙명, 산패(酸敗)** — 유통기한을 결정하는 지방 산화, 그리고 질소충전
4. **상온 견과는 저자본에 유리한 편** — 냉동 아이스크림과 정반대의 물류 구조

> 앞선 [`저당젤리`](예시_시나리오_저당젤리.md)(상온·무재고)·[`아이스크림`](예시_시나리오_라라스윗_아이스크림.md)(냉동·R&D) 편과 비교해 읽으면 식품 카테고리별 차이가 선명해집니다.

## STEP 1 — 기획: 시즈닝 견과의 3대 개발 난제

> **"견과에 맛을 입히는 게 쉬워 보여도, 실제 개발은 세 가지 싸움이다."**

| 난제 | 무엇이 문제 | 지배 변수(STEP 3 DOE) |
|---|---|---|
| **부착률** | 시즈닝 파우더가 견과에 안 붙고 봉지 바닥에 떨어짐 | 코팅유(바인더) |
| **바삭함** | 눅눅하거나 덜 고소함 | 로스팅 |
| **산패** | 견과 지방이 산화해 쩐내 → 유통기한 결정 | 코팅유·로스팅·포장 |

> **"핵심 긴장: 시즈닝을 잘 붙이려면 코팅유를 늘려야 하는데, 오일이 많아지면 산패가 빨라진다. 이 트레이드오프를 실험으로 잡는다."**

## STEP 2 — 처방·공정 (`formulas/honey-butter-almond/v1.yaml`)

```yaml
product: 허니버터 시즈닝 아몬드
slug: honey-butter-almond
regime: food
product_category: 견과류가공품
base_batch_g: 1000
phases:
  - name: A (로스팅·오일 코팅)
    process: 아몬드를 로스팅하고, 코팅유를 분무해 표면을 코팅(파우더 부착용 바인더)
    ingredients:
      - { id: roasted-almond, percent: 78.0 }
      - { id: coating-oil, percent: 3.0 }       # 바인더 — 부착률 좌우
  - name: B (시즈닝 텀블링·건조)
    process: 텀블러에서 시즈닝 파우더를 넣어 균일 부착 후 저온 건조
    ingredients:
      - { id: sugar, percent: 8.0 }
      - { id: honey-powder, percent: 5.0 }
      - { id: butter-powder, percent: 3.0 }      # 우유 알레르기
      - { id: refined-salt, percent: 1.5 }
      - { id: yeast-extract, percent: 1.5 }      # 감칠맛
packaging:
  - { id: nut-pack-30g, qty_per_unit: 1 }        # 질소충전 봉지
net_weight_g: 30
```

> **"공정 순서가 곧 품질이다: 로스팅으로 고소함·바삭함을 만들고 → 코팅유로 표면을 적셔 → 시즈닝 파우더를 텀블러로 균일 부착 → 저온 건조. 오일이 파우더의 '접착제' 역할을 한다."**
> **"플레이버 확장은 상 B의 시즈닝 파우더만 교체하면 된다(와사비·콘칩…). 상 A(견과·로스팅·코팅)는 공통 플랫폼."**

## STEP 3 — R&D: 부착·바삭·산패를 실험으로 지도화 (`doe analyze`) ★

> **"코팅유 얼마? 시즈닝 얼마? 로스팅 얼마나 세게? 2³ 완전요인으로 8배치만 만들어 방향을 잡는다."**

```bash
uv run brandlab doe analyze experiments/doe/seasoning-nut-screening.yaml
```
```
주효과 — 시즈닝 견과 스크리닝
  인자        부착률  바삭함  맛강도  고소함  산패위험
  oil         +2.00   -1.00   +0.00   +0.00   +2.00
  seasoning   +0.00   +0.00   +2.00   +0.00   +0.00
  roast       +0.00   +2.00   +0.00   +2.00   +1.00
해석
  · oil이(가) 부착률에 가장 큰 영향(+2.00)
  · roast이(가) 바삭함에 가장 큰 영향(+2.00)
  · seasoning이(가) 맛강도에 가장 큰 영향(+2.00)
  · roast이(가) 고소함에 가장 큰 영향(+2.00)
  · oil이(가) 산패위험에 가장 큰 영향(+2.00)
```

> **그래프를 읽으며 결정한다:**
> - **코팅유(oil)↑ → 부착률 +2**(가장 큼). 시즈닝을 붙이는 건 오일이다.
> - **하지만 oil↑ → 산패위험 +2, 바삭함 −1.** **"오일은 양날의 검"** — 많이 넣으면 잘 붙지만 눅눅하고 쩐내가 빨라진다.
> - **로스팅(roast)↑ → 바삭함 +2, 고소함 +2**(둘 다 지배). 식감·풍미는 로스팅이 만든다. (단 산패위험 +1도 있어 과로스팅 주의.)
> - **시즈닝(seasoning)↑ → 맛강도 +2.** 맛 세기는 파우더 양으로.
>
> **의사결정:** "부착에 필요한 **최소한의 오일**만 쓴다(산패 억제). 바삭함·고소함은 로스팅으로 확보하되 과하지 않게. 맛은 시즈닝 양으로 조절. → **코팅유는 낮게, 로스팅은 중강, 시즈닝은 취향껏.**"

> *[홈 테스트 시행착오]*
> - 1차: 잘 붙으라고 오일을 많이 → **"손에 기름 묻고, 2주 만에 쩐내."** → DOE의 oil→산패 +2 실측 확인.
> - 2차: 오일 줄이니 시즈닝이 안 붙음 → **"오일 대신 꿀분말을 살짝 녹여 점착성 보강."** (바인더를 오일+당으로 분산)
> - 3차: 로스팅을 강하게 → 고소하지만 **"쓴맛·산패 빨라짐."** → 중강으로 후퇴.

**➡️ 배울 점:** 시즈닝 견과 R&D의 핵심 긴장은 **"부착률(오일) ↔ 산패(오일)"**. DOE가 이 트레이드오프를 숫자로 드러낸다. 오일을 최소화하고 부족한 점착은 다른 수단(당·분무 방식)으로 메운다.

✅ **게이트:** run 8개 확인. 부착·바삭·산패를 지배하는 변수를 파악하고 오일 최소화 방향을 잡았는가?

## STEP 6 — 산패·유통기한: 견과의 숙명 (안정성) ★카테고리 핵심

> **"견과 제품의 성패는 '얼마나 안 쩌느냐'다. 지방이 44%라 산화(산패)가 최대 품질 리스크."**

```yaml
# experiments/stability/NUT-001-가속.yaml (개념)
sample_id: NUT-001
formula_ref: honey-butter-almond v1
condition: 45C          # 가속 산패 시험(실온 유통기한 추정)
start_date: 2026-08-24
observations: []          # 관찰: 산가/과산화물가, 쩐내, 눅눅함, 색
```

> **산패를 늦추는 4가지 레버(STEP 3 DOE와 연결):**
> 1. **코팅유 최소화** — 표면 유리지방↓ (DOE: oil→산패 +2)
> 2. **과로스팅 회피** — (DOE: roast→산패 +1)
> 3. **질소충전 포장** — 봉지 산소를 질소로 치환(산화 지연) · 차광 필름
> 4. **산화방지·탈산소제** — 필요 시 혼합토코페롤·탈산소제 동봉
>
> ⚠️ **이 도구가 대체 못 하는 것:** 산가·과산화물가 **실측 시험**과 미생물·HACCP은 **시험·시설** 영역이다. 도구는 처방·영양·원가·표시·규제와 "언제 관찰할지" 추적만 돕는다.

✅ **게이트:** 45℃ 가속시험으로 소비기한 근거 확보 + 질소충전/포장 산소차단 검증.

**견과가 저자본에 유리한 이유(젤리·아이스크림과 비교):**

| 요소 | 시즈닝 견과 | 저당 젤리 | 저당 아이스크림 |
|---|---|---|---|

**➡️ 배울 점:** 같은 배송비 함정이라도 **상온·장기보관·오프라인 친화** 덕에 견과는 1인이 풀기 쉽다. 냉동(아이스크림)과 정반대.

## STEP 8 — SKU 확장 전략: 플레이버 파이프라인 (저자본의 무기)

> **"허니버터 하나로는 금방 질린다. HBAF처럼 '이번 달의 맛'을 계속 낸다. 그런데 신제품마다 처방을 새로 개발하면 1인은 못 버틴다."**

**플랫폼(공통 플랫폼 + 파우더만 교체) 방식:**
- **상 A(견과·로스팅·코팅) = 공통.** 상 B의 **시즈닝 파우더만 교체**해 새 플레이버.
- 새 플레이버 = 새 처방 버전(`formulas/wasabi-almond/v1.yaml` 등) → `nutrition`·`label`·`cost` 그대로 재사용.
- 규제비용은 STEP 0에서 봤듯 **SKU를 늘려도 0원**(일반식품).

```
플레이버 파이프라인 운영:
□ 공통 베이스(견과·코팅) 고정, 시즈닝 파우더 레시피만 관리
□ 신맛마다 DOE는 '맛강도(seasoning)'만 재조정(부착·바삭은 공통 플랫폼서 해결)
□ 각 SKU nutrition/label/원가를 한 번씩 확인(알레르기·나트륨 달라질 수 있음)
□ 반응 좋은 맛만 상시화, 나머지는 한정판으로 소진(재고 리스크↓)
```

**➡️ 배울 점:** 저자본 견과 브랜드의 성장 엔진은 **"공통 플랫폼 + 시즈닝 교체"** 로 신제품 비용을 최소화하고, **일반식품 SKU 0원** 구조를 활용한 **플레이버 다양화**다.
