# 시나리오 — 순한 수분 로션 만들기 (초보자, 처음부터 끝까지)

> **이 문서는 무엇인가**
> 실험 초보인 1인 창업자가 **brand-lab 플랫폼(화면)만으로** 로션 하나를
> 기획→처방→사전점검→제조→테스트→라벨→원가→공장까지 끌고 가는 전 과정입니다.
> **로션(O/W 유화)은 가장 어려운 제형**이라, 여기서 막히던 사람도 이 흐름을 한 번 타면
> 밤·오일·디퓨저는 쉽게 느껴집니다. (커리큘럼 `사업_데일리루틴_커리큘럼.md`의 **ACT4**)
>
> **아래 숫자·출력은 실제 이 플랫폼에서 나온 값입니다.** 직접 따라 하면 똑같이 재현됩니다.
> 단, 모든 **규제·배합한도·비용 수치는 예시**이며 출시 전 **식약처 고시 원문**과 대조하세요.
> 이 문서는 처방 개발(집=R&D)까지입니다. **판매용 제조는 CGMP 공장에 위탁**합니다.

관련 파일(이 시나리오로 실제 생성됨):
`formulas/basic-lotion/v1.yaml`(첫 시도) · `v2.yaml`(개선) · `experiments/doe/basic-lotion-screening.yaml`

---

## STEP 0 — 기획: "순한 수분 로션을 만들어볼까?"

머릿속 생각부터 정리합니다.

- **누구에게?** 건조하지만 자극에 예민한 피부. "성분 순한 데일리 로션".
- **핵심 컨셉?** 향·색소 최소, 보습(글리세린·히알루론산·스쿠알란·시어버터), 매일 발라도 부담 없는 가벼운 발림.
- **제형?** 물+기름을 섞은 **O/W(수중유형) 에멀전**. → 유화(乳化)가 성패를 가른다.
- **왜 어려운가?** 물과 기름은 원래 안 섞인다. **유화제**로 억지로 붙여놓는 것이라,
  조합이 틀리면 며칠 뒤 **기름이 뜨는 층분리**가 온다. 초보 실패 1순위.

> 💡 이 시나리오의 진짜 교훈은 여기 있습니다: **"비커에 넣기 전에, 유화가 될 조합인지 숫자로 먼저 검증"**.
> 플랫폼의 **사전점검(HLB)** 이 그걸 해줍니다.

---

## STEP 1 — 규제판정: "이거 무슨 법이지? 돈은 얼마 드나?"

만들기 전에 규제부터. **사이드바 → 규제판정** 페이지에서:

- **용도** `body` · **기능** `moisturize` · **제형** `liquid` · SKU 5 · 검토기간 5년

**실제 출력**
```
가능한 레짐/카테고리 :  cosmetics (기초 화장품)
적합성             :  OK
최저비용 경로        :  기초 화장품 — 총 규제비용 100,000원
```

→ 로션은 **화장품법** 적용. 화장품은 **SKU를 늘려도 품목당 시험비가 0원**이라(등록비 위주),
향/컨셉 배리에이션을 붙이기 좋은 구조. "아, 디퓨저(생활화학제품)랑은 다른 법이구나"만 이해하면 됩니다.

> 규제비용 100,000원은 **예시**입니다. 실제는 화장품책임판매업 등록 + CGMP 위탁 구조를 식약처 기준으로 확인.

---

## STEP 2 — 원료 준비: "뭘로 만들지?" (원료 페이지)

**사이드바 → 원료**. 로션에 필요한 4개 그룹을 확인합니다.

| 그룹 | 원료(id) | 역할 |
|---|---|---|
| 수상 | `water`(정제수), `glycerin`, `sodium-hyaluronate`, `xanthan-gum` | 보습·점증 |
| 유상 | `squalane`, `shea-butter`, `cetyl-alcohol` | 에몰리언트·컨시스턴시 |
| 유화제 | `glyceryl-stearate-citrate` | 물·기름을 붙이는 핵심 |
| 냉각첨가 | `phenoxyethanol`, `hexanediol`(보존제), `tocopherol`(산화방지), `lavender-eo`(향) | 열에 약해 나중에 |

**꼭 볼 것**: 표에서 **붉은 행 = 화장품용 아님 또는 CoA 없음**. 로션에 쓸 원료는 붉은 행이면 안 됩니다.

> **원료가 없으면? — 등록해 보기 (➕ 새 원료 등록)**
> 원료 페이지 위 **➕ 새 원료 등록**을 펼쳐 id·이름·INCI·분류를 넣고 등록하면 즉시 처방에서 쓸 수 있습니다.
> (백업 후 저장되고, 값이 틀리면 자동 롤백됩니다.) 나중에 CoA·단가는 **✏️ 원료 수정**으로 채우면 됩니다.

## STEP 3 — 처방 생성: 첫 시도 v1 (처방 페이지 ➕)

**사이드바 → 처방 → ➕ 새 처방 생성**. 이렇게 입력합니다.

- 제품명 `순한 수분 로션` · slug `basic-lotion` · 버전 `1` · 레짐 `cosmetics`
- 제품형태 `leave_on` · 상태 `개발중` · 기준 배치 `200`

**원료 표**(상별로 묶고, percent 합계 100):

| 상 | 원료 id | percent |
|---|---|---|
| A | water / glycerin / sodium-hyaluronate / xanthan-gum | 72.8 / 5 / 0.1 / 0.3 |
| B | glyceryl-stearate-citrate / cetyl-alcohol / squalane / shea-butter | 4 / 4 / 9 / 1 |
| C | phenoxyethanol / hexanediol / tocopherol / lavender-eo | 1 / 2 / 0.5 / 0.3 |

표 아래 **"현재 percent 합계: 100.00"** 초록불을 확인하고 **처방 생성**.
→ `formulas/basic-lotion/v1.yaml` 생성. "리치하게 스쿠알란 9%나 넣었으니 촉촉하겠지?" 하고 다음으로.

## STEP 4 — 사전점검: "어라, 위험이 떴네?" (핵심 STEP)

**사이드바 → 사전점검 → `basic-lotion v1` 선택.**

**실제 출력**
```
HLB 유화 균형 :  ⛔ 위험
   공급 HLB 10.0  vs  요구 HLB 12.57  (Δ -2.57)
   — 불일치. 유화 깨짐(층분리) 위험. 유화제 종류/비율 재조정 필요
   유화제: glyceryl-stearate-citrate  ·  유상: cetyl-alcohol, squalane, shea-butter

배합한도 점검 :  페녹시에탄올 1.0% — 도달 (한도 1.0%)

종합 사전점검 :  ❌ 확인 필요
```

**무슨 일이 일어난 건가 (초보가 반드시 이해할 부분):**
- **요구 HLB 12.57** = 내가 넣은 오일들(스쿠알란·세틸알코올·시어버터)이 "이 정도 친수성 유화제가 있어야 물에 잘 섞여"라고 요구하는 값. 리치한 오일일수록 높다.
- **공급 HLB 10.0** = 내가 쓴 유화제(글리세릴스테아레이트시트레이트) 하나가 실제로 주는 값.
- **Δ -2.57**: 공급이 요구보다 한참 부족 → **기름을 다 못 붙잡음 → 층분리 위험.**
- 덤으로 **페녹시에탄올이 배합한도 1.0%에 도달**(딱 맞음). 더 넣으면 위반. 지금은 경고 수준.

> 이걸 **비커에 넣기 전에 숫자로** 잡았다는 게 핵심입니다. 안 그랬으면 이틀 저어 만들고, 일주일 뒤 기름 뜨는 걸 보고 좌절했겠죠. "이렇게 하니까 안되네. 유화제를 바꿔보자."

## STEP 5 — 수정: 공동유화제 추가 → 새 버전 v2 (처방 수정)

**진단**: 공급 HLB가 부족하다 → **HLB 높은 유화제를 섞어 공급값을 올리자.**
`polysorbate-80`은 HLB 15의 고친수성 유화제. 이걸 **공동유화제**로 조금 넣으면 공급 HLB가 올라간다.

> **원료에 HLB 값이 없다면? — ✏️ 원료 수정**
> 유화제인데 HLB 칸이 비어 있으면 사전점검이 그 원료를 유화제로 못 셉니다.
> 원료 페이지 **✏️ 원료 수정**에서 `polysorbate-80`의 HLB를 `15.0`으로 채워주세요.
> (이 시나리오의 데이터엔 이미 15.0이 들어 있습니다.)

**처방 페이지 → ✏️ 처방 수정 → `basic-lotion v1` 선택** → 값이 자동으로 채워집니다.
유상(B)을 이렇게 바꿉니다:

- `glyceryl-stearate-citrate` 4 → **3**
- **`polysorbate-80` 2 추가** (HLB 15)
- 나머지 유상(세틸·스쿠알란·시어)·수상은 그대로, `water` 72.8 → **71.8**(합계 100 맞춤)

**저장 방식: "새 버전으로 저장 (v2, 권장)"** 선택 → 저장.
→ `basic-lotion/v2.yaml` 생성(`parent_version: 1` 기록). **원본 v1은 그대로 남아** 나중에 버전비교 가능.

**다시 사전점검 → `basic-lotion v2`:**
```
HLB 유화 균형 :  ✅ 적합
   공급 HLB 12.0  ≈  요구 HLB 12.57  (Δ -0.57)  — 유화 안정 예상
종합 사전점검 :  (HLB 통과 · 보존제 도달 경고만)
```

→ **공급 12.0 ≈ 요구 12.57**. 유화제 2종 조합으로 공급값을 끌어올려 균형을 맞췄습니다.
"이제 됐다. 만들어보자." 이게 R&D의 리듬입니다 — **숫자로 실패를 예측하고, 고치고, 재확인.**

> ⚠️ HLB는 **"유화가 될 만한 조합인가"의 정성 판정**입니다. 적합이어도 실제 유화·안정성은
> 파일럿 배치와 안정성 시험으로 최종 확인해야 합니다(STEP 8).

## STEP 6 — 배치 지시서 → 실제 제조 (주말 랩)

**처방 페이지 → `basic-lotion v2` → 배치 크기 100g** → **⬇️ 배치 지시서 다운로드**.

**실제 100g 환산(발췌)**
```
[A 수상]   정제수 71.80 · 글리세린 5.00 · 히알루론산 0.10 · 잔탄검 0.30 g
[B 유상]   글리세릴…3.00 · 폴리소르베이트80 2.00 · 세틸알코올 4.00 · 스쿠알란 9.00 · 시어버터 1.00 g
[C 냉각]   페녹시에탄올 1.00 · 1,2-헥산다이올 2.00 · 토코페롤 0.50 · 라벤더오일 0.30 g
```

**유화 제조 순서 (로션의 정석):**
1. **수상(A)** 과 **유상(B)** 을 **각각 70~75℃로** 가열(간접 가온: 핫플레이트/수조. 직화 금지).
   - 팁: 잔탄검은 뭉치니 글리세린에 먼저 개어서 물에 넣는다.
2. **같은 온도**에서 A에 B를 부으며 **호모믹서로 2~3분 유화**(온도 안 맞으면 유화가 깨짐).
3. **40℃ 이하로 냉각**한 뒤 **C(보존제·향·산화방지제)** 투입(열에 약함).
4. 용기에 충전. 라벨·제조일 기록.

> 🔒 안전: 가열은 반드시 간접, 환기·보호구는 `홈랩_장비구축_가이드.md` 준수.

## STEP 7 — 배치기록: "실제로 얼마나 나왔나" (배치기록 페이지)

**배치기록 → 새 기록지 생성 → `basic-lotion v2`, 100g → 저장.**
제조 후 파일에 실측을 채웁니다:
- `yield_g`(회수량, 예: 94g → **수율 94%**. 비커·믹서에 묻어 손실나는 게 정상)
- `ph`(피부 제품 목표 **4.5~6.0**. 벗어나면 구연산/NaOH로 조정 — 원료에 이미 있음)
- `observations`(외관·향·발림감. "가볍게 발리고 층분리 없음")

**기록 요약** 탭에서 배치가 표로 쌓이고, pH가 범위 밖이면 ⚠로 표시됩니다.
→ 이게 나중에 공장에 "우리는 이렇게 재현성 있게 만든다"를 보여줄 **자산**입니다.

## STEP 8 — 테스트: DOE + 안정성 (실험 페이지)

개발의 핵심 두 가지. **감이 아니라 데이터로.**

### 8-1. DOE — "무엇이 무엇을 지배하나" (실험 → DOE 분석)
**➕ 새 DOE 설계 생성**: 인자 `emulsifier / oil / humectant`, 평가항목 `유화안정성, 보습감, 발림성, 끈적임`
→ **2^3 = 8런 골격 자동 생성**. 벤치에서 8개를 만들어 관능 평가한 뒤,
**✏️ 점수 입력/수정** 표에 점수를 채웁니다(factor_values는 읽기전용).

**실제 주효과 출력**
```
emulsifier → 유화안정성 +2.0
oil        → 보습감 +2.0 ,  발림성 -2.0
humectant  → 끈적임 +2.0
```
**해석(R&D 결론):**
- 유화제 ↑ → 유화 안정 ↑ (단 너무 많으면 비누냄새·비용). 
- 오일 ↑ → 보습 ↑ 이지만 **발림이 무거워진다**(트레이드오프). "가벼운 데일리" 컨셉이면 오일 과하지 않게.
- 글리세린 ↑ → **끈적임 ↑**. 보습과 끈적임 사이 균형점을 찾는다.
→ 다음 버전(v3)의 방향이 숫자로 잡힙니다.

### 8-2. 안정성 — "시간이 지나도 안 변하나" (실험 → 안정성 시험)
**➕ 새 안정성 시료 등록**: 시료ID `BL-001`, 조건 `45C`(가속), 시작일 오늘 → 등록.
→ **관찰 예정일(1/2/4/8주)이 자동 계산**됩니다. (RT·4℃ 시료도 같이 등록 권장)

매 관찰일마다 **✏️ 관찰 기록 입력/수정** 표에 한 행씩 추가:
`날짜 · 외관 · 분리 · 색 · 냄새 · 경도 · 판정 · 비고`.
- **관찰일을 놓치면 그 시점 데이터가 사라진다** → 화면이 **⏰ 밀린 관찰**로 잔소리해 줍니다.
- 로션은 특히 **층분리·변색·변취·pH 변화**를 봅니다. 45℃에서 4~8주 버티면 상온 유통 근거가 됩니다.

> ⚠️ 물이 든 제품은 **미생물·방부력(챌린지) 시험**이 별도로 필수입니다 — 이건 **외부 시험 랩**에 맡깁니다.

## STEP 9 — 라벨: 전성분 · 알러젠 (라벨 페이지)

**라벨 → `basic-lotion v2`.** 화장품이라 전성분·알러젠·표시의무·배합한도 화면이 뜹니다.

**실제 전성분(함량 내림차순)**
```
Aqua, Squalane, Glycerin, Cetyl Alcohol, Glyceryl Stearate Citrate, Polysorbate 80,
1,2-Hexanediol, Butyrospermum Parkii (Shea) Butter, Phenoxyethanol, Tocopherol,
Xanthan Gum, Lavandula Angustifolia (Lavender) Oil, Sodium Hyaluronate,
Linalool, Limonene, Geraniol
```

**실제 알러젠 표시대상** (leave_on 임계값 0.001%)
```
리날룰(Linalool)   0.09%   ← 표시 필요
리모넨(Limonene)   0.003%  ← 표시 필요
제라니올(Geraniol) 0.0015% ← 표시 필요   (모두 라벤더오일에서 유래)
```
**배우는 것**: 향료 0.3%만 넣어도 그 안의 **알러젠 성분이 개별 표시 대상**이 됩니다.
전성분 맨 끝에 Linalool·Limonene·Geraniol이 자동으로 붙는 이유예요. 향을 줄이거나 알러젠 프리 향으로 바꾸면 표시 부담이 줄어듭니다.

> 라벨 결과는 1차 스크리닝입니다. 최종 표기는 식약처 고시·전문가 검토로 확정하세요.

---

## STEP 10 — 원가: "팔면 남나?" (원가 페이지)

**원가 → `basic-lotion v2` → 주문 1,000개 · 판매가 22,000원.**

**실제 출력**
```
개당 원가   1,296원  (원료 496 + 부자재 800: 50ml 유리자)
개당 공헌이익 8,889원
마진(실매출 대비) 44.4%
```
**해석:** 디퓨저와 달리 로션은 **원가 대비 판매가 여력이 커서** 낱개 온라인도 마진이 납니다(공헌이익 +8,889원).
단, MOQ(유리자 최소주문)로 초도 자본이 묶이니 **MOQ 병목** 표와 **손익분기 수량**을 함께 보세요.
가격을 바꾸며 **판매가별 마진 곡선**으로 목표 마진 지점을 찾습니다.

> 원가 가정(배송비·수수료·반품률)은 `config.yaml`의 예시값입니다. 실제 견적으로 교체하세요.

## STEP 11 — 공장 이관 준비

집에서 **처방(v2) + 배치기록(수율·pH) + 안정성 데이터 + 원가 + 전성분**을 확보했습니다.
이제 **제품표준서** 페이지로 이 모두를 1문서로 내려받아 **OEM/ODM 공장**에 넘깁니다.

- 화장품 판매 = **화장품책임판매업 등록 + CGMP 공장 위탁 생산**(집에서 만든 걸 파는 건 불법).
- **처방(v2 YAML)은 영업비밀** — 클라우드·외부에 함부로 올리지 않는다.
- 공장 협상·사기방지·QA/QC는 `예시_시나리오.md`의 STEP9+ 참고.
