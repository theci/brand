# 빠른 반복 R&D 사이클 — 설계·제조·즉시판정·접기·기록

> **누구를 위한 문서인가**
> "설계 → 즉시 실험 → 아니면 빠르게 접고 다음"의 **빠른 반복**에서 성취감을 느끼는 1인 개발자가,
> 안정성(몇 주)에 발 묶이지 않고 **하루에도 여러 번 접고 다시 시작**하도록 사이클을 구성하는 법.
> 손 실무는 [홈랩 제조·보관·세척 가이드](홈랩_제조_보관_세척_가이드.md), 개선 원칙은 [산뜻보습로션 STEP 5](../사업/사업_시나리오_산뜻보습로션.md).

---

## 0. 핵심 구조 — 깔때기(빠른 루프 + 느린 루프)

```
빠른 루프 (당일, 여러 개)   →   살아남은 것만(keeper)   →   느린 루프 (백그라운드, 몇 주)
설계·제조·즉시판정·접기               keeper 큐                    안정성·관능
```

- **대부분은 "당일에" 접는다** — 유화 깨짐·pH 이상·사용감 별로·백탁·냄새 → 즉시 폐기, 다음.
- **극소수 keeper만** 안정성 큐로. 이건 백그라운드로 익으니 **빠른 루프를 막지 않는다.**
- 이래야 "빠르게 접고 다시"의 리듬이 안정성 8주에 묶이지 않는다.

---

## 1. 빠른 루프 — 당일 판정 (내 무대)

| 단계 | 도구/장비 | 즉시 피드백 |
|---|---|---|
| ① 가설 1개 → 처방 % | `처방` 페이지 | — |
| ② **사전점검**(HLB·한도·충돌·보존·유수분) | `사전점검` | **비커 전에** 말 안 되는 처방 걸러냄 |
| ③ 소량 제조 | HS5Pro·HZ-400 | — |
| ④ 즉시 측정 | 눈·코·pH미터 | 유화 O/X·pH·사용감·백탁·끈적임·냄새 |
| ⑤ 스핀테스트 30분 | 원심분리기 | 유화 조기 합불(분리?) |
| ⑥ 판정·기록 | `배치기록`·**`빠른 시험 로그`** | 접기 / keeper 큐 |
| ⑦ 세척·소독 → 다음 | 70% 알코올 | — |

> 💡 **②사전점검이 가장 빠른 "접기"** — 만들기도 전에 탈락시켜 시간을 최大 절약.

---

## 2. 느린 루프 — keeper만, 백그라운드

- 45℃·RT·4℃·동결융해 안정성(`실험·안정성`) + 관능(`관능·패널`).
- **여러 keeper를 인큐베이터에 모아** 한꺼번에 돌린다. 그 사이 나는 계속 빠른 루프.

---

## 3. ★정확한 피드백 — "뭘 바꿔야 하나" 치트시트

빠른 반복의 실력은 **증상을 보고 정확히 한 축을 바꾸는 것**. (원료가 헷갈리면 도감·나에게 물어보기)

| 증상/목표 | 바꿀 축 (한 번에 하나) |
|---|---|
| 너무 묽다 | 점증(**세틸/지방알코올·검**) 0.3~0.5%↑ 또는 유상 소폭↑ |
| 너무 되다·무겁다 | 점증↓, 유상↓, 옥클루시브(버터)↓ |
| **층분리(유수분 갈라짐)** | 온도 ±5℃ 맞춤, **고전단(HZ-400)↑**, 유화제↑, `사전점검` HLB 확인 |
| 백탁·허옇게 뜸 | 오일↓, 유화제 **최소**, (선택) 실리콘 소량 |
| 끈적임 | 글리세린↓ → **베타인/프로판다이올** 대체 |
| 유분감·번들 | 가벼운 에몰리언트(**스쿠알란/MCT**), 유상↓, 실리콘 |
| 겉돌고 흡수 안 됨 | 가벼운 에몰리언트/실리콘, 유화제 점검 |
| pH 높음 | **시트릭/락틱애씨드** 희석액 소량 |
| 보습 부족 | 수상 **휴멕턴트(글리세린·HA·판테놀)**↑, 유상 소폭↑ |
| 진정 원함 | **판테놀·알란토인·마데카소사이드·베타글루칸** 소량 추가 |
| 쩐내(산패) | **토코페롤**·EDTA, 신선 오일, 냉암 보관 |
| 곰팡이·오염 | 보존제 재설계 + 소독 철저 |
| 향 과함 | EO/향료↓ |

> ⚠️ **접는 신호 vs 튜닝**: 유화 깨짐·pH 크게 벗어남·악취·도저히 아닌 사용감 = **즉시 접기**. 묽음·약간 무거움 = **접지 말고 한 축 튜닝**. 당일 "승리"도 **안정성 확인 전엔 과신 금지**.

---

## 4. 흥미를 유지시키는 3장치

1. **한 세션에 여러 변형 = DOE.** 8개 변형을 한 번에 만들어 나란히 비교(`실험·DOE`). "여러 개 빨리"엔 최적이자 최효율.
2. **접은 것도 데이터.** "왜 안 됐다"를 `빠른 시험 로그`에 즉시 → 같은 실패 반복 X, **진행이 눈에 보임**.
3. **미장플라스.** 계량·소독·용기를 미리 세팅 → 세척 후 바로 다음 배치로.

---

## 5. 한 세션 리추얼 (반복 템플릿 — 벽에 붙이기)

```
1. 소독·계량 세팅 (10분)               ← 70% 알코올, 유산지, 저울, 온도계
2. 변형 3~6개 제조 (사전점검 통과분만)   ← HS5Pro + 냄비중탕 + HZ-400
3. 즉시 측정·기록 (유화·pH·사용감·백탁·냄새)
4. 스핀테스트 30분 → 조기 합불
5. 판정: 접기 / keeper 큐로            ← 빠른 시험 로그에 한 줄씩
6. 세척·소독 (한꺼번에)
7. 다음 세션 가설 1줄 메모 → 끝
```

**리듬 제안:** 주 2~3회 세션 × 세션당 3~6배치. keeper만 8주 안정성 큐로.

> 💡 **속도 팁:** 냉각이 사이클의 병목 → **아이스배스(큰 볼+얼음)로 빠르게 식히면** pH 측정·다음 배치가 앞당겨진다. 비커 세트를 여러 개 두고 **배치1 식히는 동안 배치2 제조**(병렬).

---

## 6. 빠른 사이클용 추가 장비·소모품

기존 세트(HS5Pro·HZ-400·OC-15S·저울·pH·인큐베이터)에 **속도·병렬·기록**을 더한다.

**⚡ 속도를 올리는 것 (우선)**
- [ ] **원심분리기 + 원심관** — 몇 주 안정성을 **30분 스핀 스크리닝**으로. *빠른 반복이면 우선순위↑*
- [ ] **아이스배스용 큰 스텐 볼/대야 + 아이스팩·얼음** — 냉각 시간 단축(사이클 병목 해소)
- [ ] **소형 비커 다수(50~100mL ×6~8) + 자석교반자 여러 개** — 변형 병렬 제조

**🏷️ 기록·큐 관리**
- [ ] **투명 유리 바이알 대량** — keeper 안정성 소분
- [ ] **라벨/마스킹테이프 + 유성펜**(또는 라벨프린터) — 빠른 표기(배치·조건·날짜)
- [ ] **폰 삼각대 + 균일 조명** — 전/후 사진 일관되게(백탁·분리 비교)

**🧰 소분·세척**
- [ ] **일회용 스포이드 다량**, 미니 스패출러·약수저 세트
- [ ] **멀티 타이머**(가열 유지·스핀·주차)
- [ ] **키친타월·70% 알코올 대량**(빠른 세척·소독)
- [ ] (선택·나중) **점도계** — 배치 간 되기 재현성 수치화

## 7. 플랫폼 매핑 — 이 사이클은 이미 플랫폼에 있다

| 사이클 단계 | 플랫폼 |
|---|---|
| 가설·처방 | `처방` |
| 비커 전 필터 | `사전점검`(5중) |
| 여러 변형 | `실험·DOE` |
| 당일 판정 기록 | **`빠른 시험 로그`**(신규) · `배치기록`(실측) |
| keeper 확인 | `실험·안정성` · `관능·패널` |
| 채택 판단 | `버전비교`(원가 포함) |
| 지속·동기 | `오늘·진행` 트래커 · 홈 대시보드 |
