# 예시 시나리오 ④ — 섬유 탈취 스프레이 · **원료 선정 집중편**

이 문서는 예시 시나리오의 네 번째 편으로, **"냄새를 어떻게 없앨 것인가"라는 원료 선정 문제**를 중심에 둡니다.
방향제(디퓨저, 3편)가 "향으로 좋은 냄새를 더하는" 제품이라면, 탈취제는 **"나쁜 냄새를 없애는"** 제품입니다. 이 차이가 원료 선정을 완전히 바꿉니다.

> 명령은 모두 이 저장소에서 **그대로 실행됩니다.** 결과는 실제로 실행해 얻은 값입니다.
> 이 결과는 1차 스크리닝이며 법적 판단이 아닙니다. 출시 전 환경부·KTR 확인이 필요합니다.

**만들 제품**: 섬유 탈취 스프레이(라벤더) · 방향제 아님 = **탈취제(분사형 액상)** · 300㎖ · 목표 판매가 9,000원 · 초도 1,000개

### 왜 이 제품을 학습용으로 골랐나

| 배울 것 | 이 제품에서 |
|---|---|
| **원료 선정 논리** | ★냄새를 "덮을까(마스킹) / 잡을까(포집) / 중화할까"를 고르는 문제 |
| 제형이 규제를 바꾼다 | **분사형(스프레이)** = 흡입 노출 → 시험비·기간이 비분사형보다 큼 |
| 물 베이스 방부 | 물 88% → 보존제 필수(로션에서 배운 것 재활용) |
| "가짜 탈취" 구별 | 기존 `fabric-deodorizer`(향으로 덮기)와 진짜 탈취(포집) 대비 |
| 사업성 판단 | 저마진 + 규제비 + 사장 재고 → **손익분기 4,301개**의 냉정함 |

## STEP 0 — 기획: 제형 하나가 규제비를 바꾼다 (`advise`)

## STEP 1 — ★ 원료 선정: 냄새를 "덮을까, 잡을까, 중화할까"

> **"탈취제의 핵심 질문은 하나다: 나쁜 냄새를 어떻게 처리할 것인가?"**
> 방법이 3가지 있고, 각각 쓰는 원료가 다르다. **어떤 방식을 고르느냐가 원료 선정의 출발점이다.**

### 탈취 3대 방식과 대표 원료

| 방식 | 원리 | 대표 원료 | 장단점 |
|---|---|---|---|
| **① 마스킹(덮기)** | 좋은 향으로 나쁜 냄새를 가림 | 향료(에센셜오일·향) | 싸고 쉽다. 하지만 **냄새가 사라진 게 아님** — 향이 날아가면 원래 냄새 복귀 |
| **② 포집(잡기)** ★선택 | 냄새 분자를 가둬버림 | **사이클로덱스트린** | 진짜로 냄새를 잡음. 향에 의존 안 함. 값이 좀 나감 |
| **③ 중화(반응)** | 냄새 분자와 화학 반응해 무취화 | 아연리시놀리에이트, 베이킹소다, 트리에틸시트레이트 | 특정 냄새(암모니아·산성취)에 강함. 대상 냄새 한정적 |

> **"기존 `fabric-deodorizer`(비분사형)를 열어보면 물+에탄올+폴리소르베이트+라벤더뿐이다. 이건 사실 ①마스킹 — 라벤더 향으로 덮는 '가짜 탈취'다. 향 날아가면 냄새가 돌아온다."**
> **"제대로 된 탈취제를 만들려면 ②포집이나 ③중화 성분이 있어야 한다. 나는 범용성이 좋은 ②사이클로덱스트린을 주력으로 고르겠다."**

### 왜 사이클로덱스트린인가

**사이클로덱스트린**은 포도당이 도넛처럼 둥글게 연결된 분자입니다. **가운데 빈 구멍(도넛 구멍)에 냄새 분자를 쏙 가둬(캡슐화)** 코가 냄새를 못 맡게 만듭니다. (섬유탈취제 대표 제품의 핵심 성분이 바로 이것입니다.)

- 특정 냄새만이 아니라 **다양한 냄새 분자**를 잡음(범용).
- 향으로 덮는 게 아니라 **실제로 냄새를 격리** → 향이 적어도 탈취됨.
- 물에 잘 녹아 스프레이에 적합.

### 등록할 원료

```yaml
# data/ingredients.yaml 에 추가
  - id: cyclodextrin
    name: 하이드록시프로필사이클로덱스트린
    inci: Hydroxypropyl Cyclodextrin
    category: 소취제
    price_per_kg: 45000
    density: 1.0
    has_coa: true
    grade: cosmetic
    cas: "128446-35-5"
```

### 나머지 조연 원료와 선정 이유

| 역할 | 원료 | 왜 이걸 골랐나 |
|---|---|---|
| 소취(주역) | 사이클로덱스트린 4% | 냄새 포집. 위 설명 |
| 용매(베이스) | 정제수 88.5% | 섬유에 뿌리는 제품이라 물 베이스가 자연스럽고 저렴 |
| 건조 보조 | 에탄올 4% | 섬유에 뿌린 뒤 빨리 마르게. **단, 분사형이라 인화성 때문에 낮게(4%)** |
| 가용화제 | 폴리소르베이트80 2% | 물에 안 녹는 향을 물에 분산 |
| 보존제 | 페녹시에탄올 1% | **물 제품 필수**(세균·곰팡이). 배합한도 1.0% |
| 향(보조) | 라벤더오일 0.5% | 은은한 잔향. 탈취가 주역이라 소량 |

> **"에탄올을 왜 4%밖에 안 넣었나? 스프레이(분사형)라 인화성이 중요하다. 에탄올이 많으면 잘 마르지만 불이 붙기 쉽고 흡입 위험도 커진다. 탈취 스프레이는 에탄올을 낮게 잡는 게 안전하다."**

✅ **게이트:** 원료 로드 확인.
```bash
uv run python -c "from brandlab.loader import load_ingredients as L; print('cyclodextrin' in L().index())"   # → True
```

## STEP 2 — 처방 작성 (`formulas/fabric-spray/v1.yaml`)

```yaml
product: 섬유 탈취 스프레이(라벤더)
slug: fabric-spray
version: 1
regime: chemical_safety
product_category: 탈취제_분사형_액상   # ★분사형 — 비분사형보다 시험비 비쌈

status: 개발중
base_batch_g: 300
phases:
  - name: A (수상 혼합)
    process: 정제수에 사이클로덱스트린을 완전히 녹인다
    ingredients:
      - { id: water, percent: 88.5 }
      - { id: cyclodextrin, percent: 4.0 }
  - name: B (가용화·첨가)
    process: 에탄올에 향을 녹여 폴리소르베이트와 함께 A에 투입, 보존제 첨가
    ingredients:
      - { id: ethanol, percent: 4.0 }
      - { id: polysorbate-80, percent: 2.0 }
      - { id: phenoxyethanol, percent: 1.0 }
      - { id: lavender-eo, percent: 0.5 }
packaging:
  - { id: trigger-spray-300ml, qty_per_unit: 1 }
fill_volume_ml: 300
```

> **처방 순서의 이유:** 사이클로덱스트린은 물에 먼저 완전히 녹여야 합니다(A상). 향은 물에 안 녹으니 에탄올에 녹인 뒤 가용화제와 함께 넣습니다(B상). 가열은 필요 없습니다.

## STEP 3 — DOE 스크리닝 (`doe analyze`)

```bash
uv run brandlab doe analyze experiments/doe/fabric-spray-screening.yaml
```
```
주효과 — 섬유탈취 스프레이 스크리닝
  인자         탈취력  건조속도  향강도
  deodorizer   +2.00    -1.00    +0.00
  ethanol      +0.00    +2.00    +0.00
  fragrance    +0.00    +0.00    +2.00
```

> **해석:**
> - **소취제(사이클로덱스트린)↑ → 탈취력 +2**, 하지만 건조속도 −1(고형분↑ → 마른 뒤 살짝 얼룩 위험).
> - **에탄올↑ → 건조속도 +2** (단, 인화성↑는 점수엔 없지만 안전 이슈).
> - **향료↑ → 향강도 +2** (탈취력엔 기여 안 함 — 향은 덮기일 뿐).
>
> **"향료를 늘려도 탈취력은 안 오른다는 게 데이터로 보인다. 진짜 탈취는 사이클로덱스트린이 한다. 향은 사용감(잔향)일 뿐."**

> **"9,000원에 팔면 마진이 6.8%밖에 안 된다. 섬유탈취제는 마트에서 싸게 파는 생활용품이라 가격을 높이기 어렵다."**
> **"손익분기가 4,301개?! 초도 1,000개로는 원금 회수도 안 된다. 게다가 트리거 보틀 MOQ가 2,000이라 1,000개(70만원어치)가 사장 재고로 묶인다."**

⚠️ **여기서 배우는 냉정한 결론:**

| 부담 요소 | 이 제품 |
|---|---|
| 제조 마진 | 낮음(9,000원에 6.8%) — 생활용품 가격 경쟁 |
| 규제비(분사형) | SKU당 485,000원 + 3년 갱신 |
| 사장 재고 | 용기 MOQ로 70만원 묶임 |
| 손익분기 | 4,301개 (초도 1,000개론 불가) |

✅ **게이트:** 제조 마진 + 규제비(48.5만/SKU·3년 갱신) + 사장 재고를 **합쳐** 사업성이 나오는가?
