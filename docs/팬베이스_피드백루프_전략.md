# 팬베이스 · 피드백 루프 전략 — "진정성으로 팬을 만들고, 데이터로 제품을 고친다"

> **이 문서는 무엇인가**
> 자본이 얇은 1인 브랜드(**오후 · OHU**)가 광고비 경쟁 대신 **① 진정성 있는 지속 소통 → 팬층 확보**,
> **② 고객 피드백을 데이터 게이트로 걸러 제품에 반영**하는 것을 **매주 실행 가능한 시스템**으로 만든 문서.
>
> **핵심 강점(왜 이 전략인가):** 파운더에게 **기술 오너십**이 있고(처방을 직접 설계·설명 가능),
> **피드백 반영 속도**가 빠르다 — 대기업이 못 하는 두 가지. 이걸 브랜드의 정체성으로 만든다.
>
> **대전제:** 회사(메가존)를 **병행**하며 진행한다. 퇴사는 [게이트](#8-퇴사-게이트--감정이-아니라-조건으로)가 다 켜진 뒤. 첫 배치 **500개는 매출이 아니라 검증 실험**이다.

## 1. 한 문장 원칙 — **소통은 빠르게, 처방은 신중하게**

소프트웨어와 달리 화장품의 "빠른 반영"엔 물리적 한계가 있다. 처방 한 번 바꾸면 **OEM MOQ + 안정성 시험 + 라벨 재표기**가 따라온다.

> **응답은 24시간, 리포뮬레이션은 분기(分期).**
> 그리고 그 **"신중하게 검증하는 과정 자체"를 콘텐츠로** 만든다.

- ❌ "촉촉함 지적받음 → 바로 오일 늘려서 재발주" (정체성 붕괴·원가 폭발·재고 리스크)
- ✅ "촉촉함 지적받음 → **하루 안에 공감·설명** → 관능/DOE로 검증 → 분기 리포뮬 or 미반영 결정 → **결정을 이유와 함께 공개**"

이 원칙 하나가 아래 모든 걸 관통한다.

## 2. 이 전략이 죽는 3가지 지점 + 가드레일

| 실패 지점 | 왜 죽나 | 가드레일 |
|---|---|---|
| **모든 피드백을 다 반영** | 제품 정체성 붕괴, 원가·재고 폭발, 버전 난립 | 피드백은 냄비로 직행 금지 → **[게이트](#4-피드백-게이트--감이-아니라-데이터로)**(관능→DOE→원가) 통과분만 |
| **목소리 큰 소수 = 전체 착각** | 비타깃 취향에 처방이 휘둘림 | 관능 도구의 **타깃/비타깃 세그먼트**로 가중. 비타깃 불만엔 처방 안 흔든다 |
| **비판에 방어적 대응** | 진정성 즉사, 캡처→확산 | **약점을 먼저 공개**. 방어 대신 "맞아요, 개선 중이에요" ([진정성 규칙](#7-진정성-가드레일--한-번-어기면-끝)) |

> 💡 당신은 이미 **촉촉함 3.75(목표 미달)** 라는 약점을 안다. **숨기지 말고 먼저 말하는 것**이 이 전략의 핵심 무기다.

## 3. 피드백 루프 OS — 6단계 파이프라인

```
① 수집 → ② 분류 → ③ 게이트(관능·DOE·원가) → ④ 로드맵 공개 → ⑤ 반영 → ⑥ 회고 공개
                                                     ↑______________________________↓
                                              (미반영도 이유와 함께 공개 → 신뢰↑)
```

| 단계 | 무엇을 | 도구/장소 | 주기 |
|---|---|---|---|
| ① 수집 | 후기·DM·오픈채팅·설문을 **한 곳에** 모음 | 소유 채널 + 스프레드시트 | 상시 |
| ② 분류 | 태그 부여([부록 A](#부록-a-피드백-분류-태그)) | 스프레드시트 | 주 1회 |
| ③ 게이트 | 반영 가치 판정 | `관능·패널`→`DOE`→`원가` | 월/분기 |
| ④ 로드맵 공개 | "요청→검증 중/예정" 공개 | 소유 채널 | 월 1회 |
| ⑤ 반영 | 처방·표기·서비스 개선 | `버전비교`·OEM | 분기 |
| ⑥ 회고 공개 | "요청→검증→결정(+이유)" | 소유 채널 | 반영·미반영 시 |

**핵심 사고:** 고객을 **평가자가 아니라 공동 개발자**로. "여러분 피드백으로 v2 나왔습니다"가 팬층의 연료다.

## 4. 피드백 게이트 — 감이 아니라 데이터로

피드백이 처방 변경까지 가려면 **3관문**을 통과해야 한다. 전부 당신이 만든 brand-lab 페이지로 돌아간다.

**게이트 1 · 관능·패널** (`관능·패널 평가` 페이지)
- 세그먼트 **타깃**으로 필터 → 항목 평균·상위2박스·목표 충족(✅/⚠️).
- **타깃에서 반복되는 약점**만 후보. 비타깃 단발 불만은 기각.
- 예: 촉촉함 타깃 3.75 < 목표 4.0 → **약점 배지** → 후보 등록.

**게이트 2 · DOE 분석** (`실험 · DOE 분석` 탭)
- "촉촉함↑" 하려면 어느 인자? 주효과로 **방향과 부작용**을 함께 본다.
- 예: 오일↑ = 보습감 +2.0 **but** 흡수력 −2.0·백탁 +1.0 → **산뜻함(USP)과 상충** → 오일 증량은 기각, 수상 휴멕턴트 축으로 우회.

**게이트 3 · 원가/공헌이익** (`원가` 페이지)
- 반영 시 개당 원가·공헌이익 변화. **공헌이익 마이너스면 반영 보류.**
- 예: 판테놀 추가 = 개당 +23.5원 → 22,000원 제품엔 무시 수준 → 통과.

> 🧭 **결정 규칙:** **타깃 반복 약점(게이트1)** + **USP 안 깨는 방향 있음(게이트2)** + **공헌이익 유지(게이트3)** = 세 개 다 ✅일 때만 리포뮬. 하나라도 ✗면 **"미반영 + 이유 공개"**로 간다(그것도 콘텐츠다).

## 5. 채널 전략 — 소유 채널 하나, 유입 채널 하나

| 구분 | 역할 | 추천 | 왜 |
|---|---|---|---|
| **소유 채널** (팬 보관소) | 팬을 **직접 소유**, 재구매·예약 | **오픈채팅** 또는 **뉴스레터** | 알고리즘에 안 휘둘림, 직접 도달 |
| **유입 채널** (발견) | 새 사람이 **발견** | 인스타/스레드/쇼츠 中 **1개** | 콘텐츠로 신뢰 → 소유 채널로 유도 |

- **원칙: 여러 채널에 흩뿌리지 말 것.** 병행 창업은 시간이 자원 — **소유 1 + 유입 1**로 시작.
- 유입 채널의 목표는 팔로워가 아니라 **"소유 채널 구독 전환"**.

### 무엇을 공개하고, 무엇은 안 하나

| 공개 ✅ (신뢰를 만든다) | 비공개 ❌ (사업을 지킨다) |
|---|---|
| 처방 **이유·방향**("유상을 왜 낮췄나") | 정확한 **전체 배합 %**(카피 방지) |
| 개발 과정·실패·**약점** | **거래처·단가·OEM명**(레버리지·계약) |
| DOE/안정성 **결과 요약** | 원가·마진 상세 숫자 |
| 고객 요청의 **처리 현황** | 미출시 신제품의 확정 일정(약속 남발 금지) |

## 6. 회사 병행 리듬 — 번아웃 없이 (주간 운영)

> 병행의 적은 실력이 아니라 **흐지부지**와 **번아웃**. 아래는 **주 2~3시간**으로 도는 최소 리듬. `오늘·진행` 페이지 리듬과 붙여서 운영.

| 요일 | 시간 | 할 일 |
|---|---|---|
| 평일(택1) | 저녁 30분 | **DM·댓글 응대**(정해둔 시간에만 — 24시간 강박 금지) |
| 평일(택1) | 저녁 30분 | 피드백 **수집→태그**([부록 A](#부록-a-피드백-분류-태그)) |
| 주말 | 1~2시간 | **주간 근황 포스트 1개** 발행 + (해당 시) 랩/관능 |
| 월말 | 1시간 | **로드맵 공개** + 게이트 판정 |

**꾸준함 > 빈도.** 매일 안 해도 된다. 주 1회 정기 포스트 + 정해진 응대 시간이면 팬층은 유지된다.

## 7. 진정성 가드레일 — 한 번 어기면 끝

- **뒷광고 표기 필수** — 대가성 체험단·협찬은 반드시 표기. (`고객 접점` 페이지가 자동 첨부)
- **질병 표방 금지** — 아토피·건선 등 "치료/개선" 표현 금지. **보습·진정 화장품**으로만. (`문구검사` 통과)
- **과장 금지** — "완벽·최고·미백" 등 금지어(브랜드 코어 ⑧). 관능은 **소표본·주관** 명시 + 표본/방법 표기.
- **방어적 대응 금지** — 비판에 변명 대신 **인정+계획**. ("맞아요, 거기 약해요. 이렇게 개선 중이에요.")
- **약속 남발 금지** — "다음 달 출시" 같은 확정 약속은 지킬 수 있을 때만. **못 지킨 약속 1개 > 안 한 약속 10개**의 타격.

## 8. 퇴사 게이트 — 감정이 아니라 조건으로

아래가 **모두** 켜지기 전엔 병행 유지. (감정·번아웃으로 결정 금지)

- [ ] 첫 배치 **완판** + **재구매율**이 나온다 (화장품은 재구매 사업)
- [ ] **반복 가능한 획득 채널** 1개 확보 (광고 없이도 유입되는 경로)
- [ ] 공헌이익 기준 **단위경제 양(+)** (`원가` 페이지로 확인)
- [ ] **6~12개월 생활비 런웨이** 확보

> 다 켜지면 퇴사는 "베팅"이 아니라 "이전(移轉)"이 된다.

## 9. 팬베이스 지표 — 허영 지표를 버려라

| ❌ 허영 지표 | ✅ 진짜 지표 |
|---|---|
| 팔로워 수 | **소유 채널 구독자 수·참여율** |
| 좋아요·조회수 | **후기 전환율**(구매→후기 작성 %) |
| 노출·도달 | **재구매율 · 재구매 코호트** |
| 일회성 매출 | **다음 배치 예약(사전예약) 수** |

> 팬층은 "숫자"가 아니라 **"다음 배치를 예약하는 사람 수"**로 센다.

## 10. 30 / 60 / 90일 로드맵 (첫 500개 연동)

**~30일 · 씨 뿌리기**
- 소유 채널 1개 개설 + 유입 채널 1개 시작
- 초기 물량 일부 → **타깃 체험단**(뒷광고 표기) → **목적은 매출 아닌 리뷰**
- 개발 서사 콘텐츠 3~5개(랩·처방 이유·약점 공개)
- 피드백 수집 스프레드시트 + 태그 체계 세팅

**~60일 · 루프 돌리기**
- 주간 근황 포스트 정착, DM 응대 리듬 안착
- 첫 **로드맵 공개** + 게이트 판정 1회
- 후기 축적 → 상세페이지에 **타깃 관능 근거·후기** 반영
- 재구매/후기 전환 **지표 추적 시작**

**~90일 · 판정**
- 500개 소진 속도·재구매·채널 유효성 리뷰
- 리포뮬 필요 시 `버전비교`로 v2 설계 → OEM 협의
- **퇴사 게이트 4개 점검** → 다음 배치 규모 결정

## 부록 A. 피드백 분류 태그

수집한 피드백에 아래 태그를 붙여 게이트로 보낸다.

| 태그 | 뜻 | 어디로 |
|---|---|---|
| `#처방` | 사용감·발림·보습·향 등 | 관능→DOE→원가 게이트 |
| `#표기` | 라벨·성분·사용법 오해 | 문구검사·라벨 개선(빠름) |
| `#서비스` | 배송·CS·패키지 파손 | 즉시 개선(처방 무관) |
| `#가격` | 가격·용량 인식 | 원가/포지셔닝 검토 |
| `#칭찬` | 강점·재구매 의사 | **근거 승격**(관능→브랜드코어 ⑤) |
| `#비타깃` | 타깃 밖 취향 | 기록만, 처방 미반영 |
