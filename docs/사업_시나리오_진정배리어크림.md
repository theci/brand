# 사업 쉐도잉 — "오후 진정 배리어 크림" (칸 단위 실습판 · 로션 라인 확장)

> **이 문서는 무엇인가**
> [`사업_시나리오_산뜻보습로션.md`](사업_시나리오_산뜻보습로션.md)로 만든 **오후(OHU)** 브랜드의 **라인 확장 크림**을,
> 같은 방식(**① 사고의 흐름 → ② 칸별 입력값 → ③ 버튼 → ④ 결과**)으로 기획→출시까지 끌고 갑니다.
> 로션편과 겹치는 설명은 줄이고, **크림이라서 달라지는 것**(유분↑·옥클루시브 관리)과
> **사전점검 5중 점검(HLB·배합한도·상용성·보존·유수분)** 을 실제 실행값으로 보여줍니다.
>
> 숫자는 저장소 예시(`barrier-cream v1`)로 **실제 실행한 값**. 규제·수치는 1차 스크리닝(출시 전 관할기관 확인).

**제품:** 브랜드 **오후(OHU)** · **"오후 진정 배리어 크림"**(50mL, 무향, 화장품). 로션의 **저녁·건조·장벽** 버전.

> 진행은 로션편과 동일하게 **`오늘·진행`** 페이지로 하루치씩. 브랜드 코어(브랜드명·톤·컬러·금지어)는 **로션에서 만든 걸 그대로 재사용**(같은 브랜드) → SKU 확장 비용 0원(화장품).

# STEP 0 · 기획 — 라인 확장의 이유부터

## 0-1. `페르소나 · JTBD` 🧑
로션 고객 중 **"낮엔 로션으로 충분한데 저녁·환절기엔 당기고 붉어진다"** 는 층을 겨냥.

| 칸 | 값 |
|---|---|
| `id` | `dry-barrier-evening` |
| `name` | `저녁 건조·장벽 약한 피부` |
| `one_line` | `환절기·냉난방으로 저녁이면 당기고 붉어지는 장벽 약한 피부` |
| `jobs(쉼표)` | `밤사이 보습 잠금, 자극 없이 진정` |
| `current_solution` | `로션만 사용 / 무거운 크림은 번들` |
| `dissatisfaction` | `로션은 밤에 부족, 크림은 무겁고 답답` |
| `priority` | `4` |

**페인:** `저녁이면 당기고 각질`(심각4×빈도4=16), `크림은 무거워 번들거림`(3×4=12).

> 💡 **결정:** 문제는 "보습 부족"이자 동시에 **"무거움"**. → 크림이되 **번들거리지 않는 유수분 균형**이 과녁(로션의 '산뜻'을 크림에서도 유지).

## 0-2~0-5. 시장·경쟁 / 문제정의 / 포지셔닝 / 브랜드코어
- **경쟁 빈틈:** "장벽 크림은 무겁고 끈적"(gaps). → 포지셔닝 프리필로 이어짐.
- **포지셔닝 문장(자동 조립):**
  > "저녁이면 당기는 장벽 약한 피부에게, 무겁기만 한 장벽 크림이 못 준 **'번들 없는 밤 보습'** 을, 유수분 균형 설계로 해결하는 **진정 배리어 크림**."
- **브랜드 코어:** 로션과 **동일 코어 재사용**(브랜드명 오후 · 톤 담백·정직 · 금지어 완벽/최고/미백). 크림은 진입점만 추가(`저녁 루틴 마지막`).

> 💡 **결정:** 새 브랜드가 아니라 **라인 확장** → 신뢰·비주얼·규제 자산을 재사용. 화장품이라 SKU 추가 등록비 0원.

## 0-6. 브랜딩 느낌 미리보기 🎨
브랜드 코어 하단 **🎨 브랜딩 느낌 미리보기**에서 로션과 **같은 팔레트**(오후 베이지·세이지·테라코타) 스와치 확인 + `무드보드 종류`=패키지 무드 → **[무드보드 프롬프트]**. → 로션과 **한 얼굴**로 이어지게(라인 통일성).

# STEP 1 · 규제판정 ⚖️
`용도`=body·`제형`=cream(→liquid)·기능=moisturize → **화장품·OK**.
> 💡 **결정:** "장벽 **강화/회복**"은 표현 주의(과장·의약품 오인 소지). **"보습·진정"** 선에서. "아토피/건선 완화" 절대 금지(질병 표방).

# STEP 2 · 원료 📦
로션 대비 **유분을 올리되(크림) 무겁지 않게**, 진정·장벽 활성을 강화.
- 유수분(유상 ↑): **시어버터**(옥클루시브=밤 잠금)·**스쿠알란·호호바**(가벼운 에몰리언트)·세틸(컨시스턴시)
- 진정·장벽: **나이아신아마이드 3%·병풀·베타글루칸·판테놀·알란토인**
- 무향, 보존제(페녹시에탄올)+보조(1,2-헥산다이올)
- 신규 원료는 **[PubChem 자동채움]** 으로 CAS·밀도. 붉은 행(CoA 없음) 배제.

> 💡 **결정:** "무거움"의 주범인 **옥클루시브(시어)는 딱 필요한 만큼(5%)**, 나머지 유분은 **가벼운 에몰리언트**로. 유수분 균형은 STEP 3에서 숫자로 확인.

# STEP 3 · 처방·사전점검 — ★5중 점검을 숫자로

## 3-1. `처방` 🧪
`barrier-cream v1`: A수상(휴멕턴트+수용성 진정) · B유상(유화제·시어·스쿠알란·호호바·세틸 = **유상 24%**) · C냉각(병풀·토코페롤·보존). 무향. 합계 100.

## 3-2. `사전점검` 🔍 — HLB·배합한도·상용성·보존·유수분
`처방 선택`=`barrier-cream v1` → **5가지가 한 화면에** 뜹니다(실행값):

| 점검 | 결과 | 의미 |
|---|---|---|
| **HLB 유화** | **적합** (공급 10.0 / 요구 9.97) | 유상을 늘려도 유화 안정 |
| **배합한도** | 초과·도달 없음 | 여유 |
| **원료 상용성(충돌)** | 충돌 없음 | 나이아신+비타민C·양이온↔음이온 등 규칙 통과 |
| **보존 시스템** | **양호** (페녹시에탄올 + 1,2-헥산다이올) | 물 크림 필수 방어 확보 |
| **제형·유수분** | **유상 24.5% → 크림** · 휴멕 8.1 / 에몰 14 / **옥클 5** / 유화 5 | 로션(유상 13.3·옥클 1.5)보다 **잠금↑** |

> 💡 **결정:** 로션은 유상 13.3%(가벼운 로션)인데, 이 크림은 **24.5%로 확실한 '크림'** + **옥클루시브 5%**(로션 1.5%↑)로 밤 보습을 잠근다. 그런데 **HLB가 9.97/10.0로 딱 맞아** 유화는 안정. **"무겁지 않은 크림"** 이 숫자로 성립. 물 크림이라 **보존 양호** 확인은 필수 게이트.
> 🎓 로션 대비 **딱 이 5중 점검이 크림 개발의 핵심**입니다 — 유분을 올리면 유화(HLB)·유수분·보존이 다 흔들릴 수 있는데, 비커 전에 전부 통과 확인.
