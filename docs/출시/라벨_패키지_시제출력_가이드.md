# 라벨·패키지 시제 출력 가이드 — 집 잉크젯으로 인쇄소 흐름 리허설

> 상태: ✅ 최신 · AI 이미지 → 일러스트레이터 → **가정용 잉크젯 시제 출력 → 실물 부착 테스트 → 인쇄소 양산**의 실무 흐름.
> **프린터**: 삼성 컬러 잉크젯 플러스S 복합기 **SL-T1685W** (A4 · 무한잉크 · Wi-Fi · 22/16 ppm)
> **함께 보기**: 🎨 [디자인 브리프] 페이지(§6 프롬프트) · 📣 [브랜딩·마케팅 완전가이드 10부](브랜딩_마케팅_완전가이드.md) · 🏢 [판매전 등록 체크리스트](판매전_등록_체크리스트.md)

> ⚠️ 규제 표기(필수기재·전성분)는 [라벨]·[디자인 브리프]가 자동 판정한 값을 **정본**으로 삼는다.
> 200mL 본품은 표시면적 `full` tier → **전성분 전체 표기 필수**(50mL 미니는 생략 가능). 디자인 전에 브리프부터 뽑을 것.

---

## 0. 대원칙 — 집 잉크젯의 역할은 "색"이 아니라 "배치·비율·가독성"

가정용 잉크젯 시제 출력로 **확인할 수 있는 것 / 없는 것**을 먼저 못박는다.

| ✅ 집에서 확인 (시제의 목적) | ❌ 집에서 확인 불가 (인쇄소에서만) |
|---|---|
| 실측 **크기·비율**(용기에 붙였을 때) | **정확한 색**(가정용 RGB 잉크젯 ≠ 인쇄소 CMYK) |
| **필수기재 가독성**(작은 글자 읽히나) | 특수 후가공(무광/유광 코팅·박·엠보) |
| 여백·정렬·정보 위계 | 스티커 **재단(다이컷)** 정밀도 |
| 곡면 부착 시 **주름·왜곡** | 방수·내유(오일) 최종 내구성 |

> 💡 **한 줄:** 집 출력은 "**인쇄소에 넘기기 전 실물로 실수를 잡는 리허설**"이다. 색·질감 최종 판단은 반드시 **인쇄소 교정쇄(proof)** 로.

## 1. 실무 전체 흐름

```
① [디자인 브리프] §6에서 프롬프트 + 필수기재·규격 확보
        ▼
② AI 이미지 생성 (배경·무드·라벨 그래픽 초안)  ※ 제품 실물·인물은 실촬영
        ▼
③ 일러스트레이터: 1:1 실측 아트보드 + 블리드·재단선·안전여백 세팅, 텍스트 벡터화
        ▼
④ SL-T1685W로 A4 100% 출력 (배율 100%, 고품질)
        ▼
⑤ 오려서 실제 용기에 부착 → 실물 테스트 체크리스트
        ▼
⑥ 수정 반복 → 확정되면 인쇄소용 파일(PDF/X·CMYK·아웃라인)로 양산 의뢰
```

**핵심:** ③에서 만드는 블리드·재단선·안전여백·1:1 실측은 **인쇄소가 요구하는 바로 그 규격**이다. 집 출력으로 이걸 미리 몸에 익히면 인쇄소 사고가 급감한다.

## 2. 프린터 이해 — SL-T1685W로 할 수 있는 것

- **최대 A4**(210×297mm). A3 불가 → 라벨·소형 패키지 전개도는 A4에 충분히 들어감.
- **무한잉크(ink tank)** → 시제를 **여러 장 부담 없이** 반복 출력 가능(반복 테스트에 유리).
- **염료 잉크젯** 특성: 색 선명하나 **물·오일에 번짐**. 화장품 라벨은 물·오일 접촉 → §4 방수 대책 필수.
- **무테두리(여백 없음)** 지원 여부는 프린터 드라이버에서 확인. 안 되면 **A4 안쪽에 재단선 넣고 오려내기**로 해결(오히려 실무와 동일).
- 용지: 일반지(배치 확인용) → **사진용지/잉크젯 라벨지**(실물 느낌 확인용) 순으로 올린다.

## 3. 일러스트레이터 파일 세팅 — 단계별 지정값

> 메뉴는 한국어(영문) 병기. 값은 **그대로 입력**하면 된다.

### 3-0. 먼저 용기를 잰다 (실측)
- 라벨 붙일 면의 가로(둘레 방향)·세로를 자로 잰다.
- 원통형이면 **최대 라벨 폭 = 둘레 = π × 지름 − 겹침 5~10mm.**
  - 예) 200mL 펌프 지름 ≈ 45mm → 둘레 ≈ 141mm → 랩 라벨 폭 **130~135mm**.
- **✅ 확정 규격 — 오후 산뜻 보습 로션 (히어로)**
  | 대상 | 용기 | 라벨 재단(trim) | 형태 |
  |---|---|---|---|
  | **본품 200mL** | 에어리스 진공 펌프 · 지름 55mm · 전체높이 174mm | **173 × 110mm** (둘레=π×55≈173) | 전체 랩(앞 디자인+뒤 정보) |
  | 미니 50mL | (같은 라인 50mL 보틀 예정) | 실측 후 확정 | 전면 |
  - 랩 폭: **173mm**(맞댐) 또는 **178mm**(뒤 5mm 겹침). 높이 110mm는 펌프 아래 평평한 구간 기준.
  - **파생 값(그대로 사용)**: 도련 포함 캔버스 **179 × 116mm** · 안전영역(텍스트 한계) **165 × 102mm** · 앞면 디자인 **~86mm** / 뒷면 정보 **~86mm** × 110.

### 3-1. 새 문서 (파일 > 새로 만들기 / File > New)
| 항목 | 값 |
|---|---|
| 프로파일 | **인쇄(Print)** |
| 단위 | **mm** |
| 폭 × 높이 | **173 × 110** (오후 산뜻 로션 200mL 확정 · 다른 제품은 §3-0 실측값) |
| 도련(Bleed) | 상·하·좌·우 각 **3mm** |
| 색상 모드(고급) | **CMYK** |
| 래스터 효과(Raster Effects) | **고(High) 300ppi** |
| 아트보드 | 1개 |

### 3-2. 안전여백 안내선 만들기
- 재단선(아트보드 경계)에서 **안쪽 4mm**에 안내선 → **텍스트·로고는 이 안쪽에만**.
- 방법: 아트보드 크기 사각형 → **오브젝트 > 패스 > 패스 이동(Object > Path > Offset Path)** = **−4mm** → **보기 > 안내선 > 안내선 만들기(View > Guides > Make Guides)**.
- 결과 3영역: 도련(바깥 3mm, 잘려나감) / 재단선 / 안전여백(안쪽 4mm, 안전지대).

### 3-3. 레이어 구성 (아래→위)
1. `bg` — AI 배경/그래픽 이미지
2. `art` — 브랜드 그래픽·라인·로고(벡터)
3. `text-legal` — 법정 필수기재 텍스트
4. `guides` — 안내선·마크(인쇄 안 됨)

### 3-4. AI 이미지 배치 (파일 > 가져오기 / File > Place)
- **'연결(Link)' 체크 해제 → 포함(Embed)** (파일 옮겨도 안 깨짐).
- 배경으로 쓰면 **도련 끝(재단선 바깥 3mm)까지 꽉** 덮기.
- **실효 해상도 300ppi 이상** 확인: 창 > 링크(Window > Links) 패널에서 PPI 확인 → 미달이면 이미지를 더 크게 재생성(줄여 쓰는 건 OK, 늘리면 깨짐).
- 배치 후 `bg` 레이어 **잠금**.
- ⚠️ **AI 이미지의 글자는 쓰지 않는다** — 배경/그래픽으로만.

### 3-5. 법정 텍스트 타이핑 (정본 = [라벨] 페이지 출력)
- [라벨] 페이지 결과를 **그대로** 입력: 제품명 / 영업자(제조판매업자) 상호·주소 / **내용량 200mL** / 제조번호 / 사용기한 또는 개봉 후 사용기간(PAO) / **전성분 전체** / 사용 시 주의사항 / (해당 시)기능성 표시.
- **최소 글자 크기(가독성 실무 기준)**: 전성분 등 소형 텍스트 **≥ 5~6pt**, 주의사항 **≥ 6pt**, 제품명은 위계상 크게. (법이 절대 pt를 못박진 않으나 원칙은 '쉽게 읽히게' — 작을수록 반려 위험)
- **텍스트 색 = K(먹) 100% 단색** 권장(작은 글자를 4도로 겹치면 핀 안 맞아 흐려짐).
- 폰트: 헤딩 = 휴머니스트 산세리프, 제조번호·날짜 = 타자기 모노 악센트.

### 3-6. 저장 & 아웃라인
- 편집 원본 **.ai 저장**(수정용, 폰트 살려둠).
- 출력·인쇄소 입고용은 **사본**에서 **문자 > 윤곽선 만들기(Type > Create Outlines)** — 글꼴 깨짐 방지. **원본엔 하지 말 것**(이후 수정 불가).

## 4. 용지·라벨지 선택 (화장품 = 물·오일 주의)

| 단계 | 용지 | 목적 |
|---|---|---|
| 1차 | **일반 A4** | 배치·비율·가독성 빠른 확인(잉크 아낌) |
| 2차 | **잉크젯 사진용지(광택/무광)** | 색감 방향·질감 느낌 |
| 3차 | **잉크젯용 라벨 스티커(A4 시트)** | 실제 용기 부착 테스트 |

⚠️ **번짐 대책(잉크젯 필수)**: 염료 잉크는 물 닿으면 번진다. 부착 테스트 전 **정착 스프레이(픽서티브)** 또는 **투명 라미네이팅 필름/방수 라벨지**로 코팅. (양산은 인쇄소에서 방수 유포지·PET·코팅으로 해결하니, 집에선 "번지는지"만 인지하면 됨)
- 곡면(펌프 보틀)엔 빳빳한 사진용지보다 **얇은 라벨지**가 주름이 적다.

## 5. SL-T1685W 출력 설정 — 단계별 지정값

### 5-0. A4 배치 (오후 산뜻 로션 200mL = 173 × 110)
- 도련 포함 **179 × 116mm** → **A4 가로(landscape) 100%**로 한 장에 들어감(210 × 297 여유).
- 세로로 **2장 tile 가능**(116 × 2 = 232 < 297) — 무한잉크 + 무분할 라벨지로 시안 2개 한 번에. 각 옆에 **버전·날짜**를 작게.
- 더 작은 라벨(미니 등)은 A4에 3~4개 복제 배치.

### 5-1. 파일 > 인쇄 (File > Print)

**일반(General)**
| 항목 | 값 |
|---|---|
| 프린터 | **Samsung SL-T1685W** |
| 용지 크기 | **A4** |
| 방향 | 라벨에 맞게 |
| 배율(Scaling) | **사용자 정의 배율 없음 / 100%** — "페이지에 맞춤(Fit to Page)" **절대 금지** |
| 배치(Placement) | 중앙(또는 원하는 위치) |

**표시 및 도련(Marks and Bleed)**
- ☑ **재단선(Trim Marks)**
- 도련(Bleed): **'문서 도련 설정 사용'** 체크 (또는 상하좌우 **3mm** 직접 입력)

**색상 관리(Color Management)**
- 색상 처리: **Illustrator에서 색상 결정(Let Illustrator determine colors)**
- 프린터 프로파일: 넣은 용지 프로파일(없으면 기본)
- → **드라이버 색보정은 끔** (아래 5-2). 색 보정은 **한쪽만** — 이중 보정 방지.

### 5-2. 프린터 드라이버 (인쇄 대화상자 > 설정/속성 / Properties)
| 항목 | 값 |
|---|---|
| 용지 종류 | 실제 넣은 용지와 **일치** (일반지 / 사진용지(광택·무광) / 라벨지) |
| 인쇄 품질 | **높음 / 최상 / 사진(Best·Photo)** |
| 색상 | 컬러 |
| 색 보정 | **끔**(Illustrator가 관리하므로) |
| 여백 없음(무테) | 지원 시 켬(전면 배경 라벨). 미지원이면 재단선 기준 오려내기 |
| 배율 | **100%**(드라이버에서도 축소 금지) |

### 5-3. 출력 순서
1. **일반지 1장** 시험 출력 → **자로 재서 실측 크기가 맞는지** 확인(배율 사고 1차 검문).
2. 맞으면 **사진용지/라벨지**로 본 출력.
3. (선택) 일반지·사진용지 각 1장 뽑아 **색 차이 기록**(가정용 잉크젯 편차 감 잡기).
4. 라벨지는 **§4 방수 코팅** 후 부착 테스트(§6).

### 5-4. 자주 나는 사고 ↔ 원인
| 증상 | 원인 |
|---|---|
| 크기가 작게 나옴 | '페이지에 맞춤' 켜짐 or 드라이버 축소 → 100%로 |
| 색이 탁함·노랑끼 | 가정용 잉크젯 정상 편차 → **색 최종판단은 인쇄소 교정쇄** |
| 작은 글자 흐림 | 작은 글자를 4도로 조판 → **K 단색**으로 |
| 배경에 흰 테두리 | 무테 미지원 → 재단선까지 오려내기 |

## 6. 실물 부착 테스트 체크리스트

출력물을 오려 실제 용기(200mL 펌프 / 50mL 미니)에 붙이고 확인:

- [ ] **비율** — 용기 대비 라벨이 크거나 작지 않은가
- [ ] **필수기재 가독성** — 전성분·주의사항 등 **가장 작은 글자**가 팔 길이에서 읽히는가
- [ ] **곡면 왜곡** — 붙였을 때 주름·기포·모서리 들뜸
- [ ] **여백·정렬** — 재단 오차를 감안해도 텍스트가 안 잘리는가(안전여백 검증)
- [ ] **정보 위계** — 제품명 → 핵심 → 필수기재 순으로 눈이 흐르나
- [ ] **번짐** — 물 한 방울·오일 손가락 문질러 번지는지(양산 방수 사양 결정 근거)
- [ ] **컨셉 부합** — 담백·정직 톤인가, 화려하게 과하지 않은가([브랜드 코어] 톤과 대조)
- [ ] **1:1 미니와 본품** — 같은 디자인이 두 사이즈에서 다 성립하는가

> 📸 각 시안은 **용기에 붙인 사진**으로 남긴다 — 그대로 개발 서사·비교 콘텐츠가 된다(진정성 자산).

## 7. 인쇄소 양산 넘기기 전 최종 체크

집 시제로 확정되면 **양산은 인쇄소**(디지털/오프셋 + 다이컷 스티커 + 코팅). 넘기기 전:

- [ ] **CMYK** 변환 완료(RGB로 넘기면 색 튐)
- [ ] **도련 3mm + 재단선** 포함
- [ ] 글꼴 **아웃라인화** 또는 폰트 동봉
- [ ] 이미지 **300dpi 이상**, 링크 임베드
- [ ] **PDF/X-1a 또는 PDF/X-4** 로 저장(인쇄 표준)
- [ ] 필수기재 최종 대조([라벨] 페이지 출력과 1:1)
- [ ] **교정쇄(proof) 요청** — 색·후가공은 실물 교정으로만 최종 확정
- [ ] 방수·내유 사양 지정(화장품 필수), 재단 형태(사각/라운드/다이컷)

## 8. 플랫폼 연결

## 9. 반복 팁 — 무한잉크의 이점 살리기

- 잉크 부담이 적으니 **A4 한 장에 시안 3~4개**(폰트 크기·여백·컬러 변주)를 나란히 배치해 한 번에 비교.
- 버전마다 **날짜·버전 표기**를 라벨 구석에 작게 넣어 출력 → 어느 시안인지 헷갈리지 않게.
- 테스트 로그(간단): `버전 / 용지 / 무엇을 바꿨나 / 결과(붙인 사진)` 한 줄씩.

> **한 줄:** 집 잉크젯은 **색을 맞추는 도구가 아니라, 인쇄소 사고를 미리 잡는 리허설 도구**다. 크기·가독성·배치·번짐을 여기서 잡고, 색·후가공은 인쇄소 교정쇄로 확정하라.
