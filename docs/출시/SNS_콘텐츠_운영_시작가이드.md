# SNS 콘텐츠 운영 시작 가이드 — "포스팅 안 하던 사람"을 위한 온램프 + AI 프롬프트 키트

> 상태: ✅ 최신 · 최종수정 2026-09-22 · 목적 = 16부작 완전가이드를 **비(非)포스터가 바로 실행**하도록 압축 + **오후(OHU) 브랜드에 미리 채운 AI 프롬프트**로 생산성 확보.
> **함께 보기(깊이)**: 📣 [브랜딩·마케팅 완전가이드](브랜딩_마케팅_완전가이드.md)(2부 콘텐츠공장·3부 채널·4~6부 채널별·7부 광고·부록B 프롬프트) · 💬 [팬베이스·피드백루프 전략](../사업/팬베이스_피드백루프_전략.md)(채널·주간리듬·공개템플릿)

> **한 줄:** 매주 새 콘텐츠를 만들지 말고 — **월 1회 원본 촬영 → AI로 12벌 리퍼포징 → 예약 발행**. 포스팅 노동이 아니라 **시스템**을 돌린다.

## 1. 왜 포스팅하나 — 목적부터 바꾼다 (제일 중요)

> ⚠️ 완전가이드 팀장의 첫 마디: **"지금 문제는 노출이 아니다. 첫 90일 목표는 매출이 아니라 증거다."**

- 목표는 **팔로워·좋아요(허영 지표)가 아니라** → ① 신뢰(증거·서사) 쌓기 → ② **소유 채널(오픈채팅 등)로 팬 전환** → ③ 재구매·사전예약.
- **이 브랜드가 SNS에서 이기는 법**: 제품 스펙 콘텐츠는 대기업이 이긴다. 작은 브랜드는 **사람 얼굴이 보이는 이야기** — 만든 이유·실패담·약점 공개. 이게 "가공하지 않은 파운더" 컨셉과 정확히 같은 무기다(대기업은 절대 못 함).

**볼 지표(적게):** 소유 채널 구독자·참여율 · 후기 전환율 · 재구매·사전예약 수. (❌ 팔로워·조회수)

## 2. 채널 세팅 — 소유 1 + 유입 1 (흩뿌리지 말 것)

| 구분 | 역할 | 추천 | 왜 |
|---|---|---|---|
| **소유 채널**(팬 보관소) | 팬 직접 소유·재구매·사전예약 | **카카오톡 채널** 또는 **오픈채팅** | 알고리즘 무관·직접 도달 |
| **유입 채널**(발견) | 새 사람이 발견 | **인스타그램**(1순위) | 파운더 실사·제형컷과 궁합, 발견 강함 |
| 검색 자산(저빈도) | 검색으로 오래 유입 | **네이버 블로그**(월 1~2회 장문) | 에버그린·SEO·긴 서사에 유리 |

- **비포스터 시작 원칙:** 인스타 1개에 먼저 집중, 블로그는 **콘텐츠 데이 원본을 장문으로 1편** 재활용(추가 노동 최소). 광고는 나중(§6).
- 유입 채널의 목표 = 팔로워가 아니라 **소유 채널 구독 전환**. 프로필·게시물 끝에 항상 "오픈채팅/카카오채널로 오세요" 유도.

## 3. 무엇을 올리나 — 12포맷, 이 브랜드 우선순위

완전가이드 12포맷 중, **담백·정직 컨셉에서 가장 센 것부터** 돌린다(주제 고갈 없음):

| 우선 | 포맷 | 왜 이 브랜드에 센가 |
|---|---|---|
| ⭐1 | **만든 이유**(창업 스토리) | 감정 연결·대기업 불가 |
| ⭐2 | **실패담**(개발 중 엎은 것) | 신뢰 급상승·진정성 |
| ⭐3 | **비하인드**(개발·제조·포장 과정) | "진짜 만든다"의 증거 |
| ⭐4 | **약점 선공개**(촉촉함 3.75 등) | 방어 대신 인정 = 해자 |
| 5 | **성분 해부**(왜 이만큼 넣었나) | 근거=화장품의 화폐 |
| 6 | **제형 클로즈업**(실촬영) | 뷰티 숏폼 최강 |
| 7 | **Q&A / 고객 후기 리액션** | 구매장벽 제거·사회적 증거 |

> 스펙 자랑 대신 **③④⑪(과정·약점·실패)** 를 중심축으로. 이게 팬을 만든다.

## 4. 어떻게 지속하나 — 콘텐츠 데이 + 1→12 (주 2~3시간)

```
[월 1회 · 콘텐츠 데이 반나절]  ← 원본 자산 한 번에 확보
0:00 주제 1개 확정(위 12포맷 순환)
0:20 촬영 — 영상 소재 + 사진 20~30장(제형·제품·손·배경) 한 번에  ※ 실촬영은 AI 불가
1:20 AI 초벌 편집(자막·컷)
2:00 §5 프롬프트로 채널별 카피 12벌 생성
2:40 예약 발행(2~4주치 걸어두기)

[나머지 날]  댓글·DM 응대(정해둔 시간에만) + (월말)피드백 공개 1회
```

**핵심: 촬영은 한 번, 활용은 열두 번.** 원본 1개 → 릴스 3 + 피드 3 + 캐러셀 1 + 스토리 5 + 블로그 1 + 스레드 3 + 카카오 1 …

## 5. AI 프롬프트 키트 (오후 브랜드 미리 채움 · 복붙용)

> 순서 원칙: **① 브랜드 자산 → ② 이번 작업 → ③ 요청 → ④ 가드(법규+진정성)**. 아래 **[A] 블록을 항상 맨 앞에** 붙인다.

### [A] 브랜드 자산 블록 (매 프롬프트 맨 앞에 복붙)
```
[브랜드 자산]
- 브랜드: 오후(OHU) · 제품: 오후 산뜻 보습 로션(200mL, 에어리스 펌프)
- 컨셉: "가공하지 않은 파운더" — 완성도가 아니라 정직함이 무기. 파운더가 직접 만들고 과정·한계를 그대로 보여준다.
- 타깃/문제: 냉난방 사무실 30대 직장인, 오후 당김 — 화장 위에도 덧바르는 산뜻 보습.
- 톤: 담백한·정직한·꾸밈없는·손때 묻은·본질에 집중한 (자랑·과장 없음)
- 애용어: 그대로·직접·과정·솔직히·아직
- 금지어(쓰지 마): 럭셔리·프리미엄·혁신적인·완벽한·최고급
- 알려진 약점(숨기지 않음): 산뜻함은 강(타깃 4.5)·촉촉함은 아직 목표 미달(3.75)
```

### [가드] 법규 + 진정성 블록 (매 프롬프트 맨 뒤에 복붙)
```
[필수 준수]
- 화장품법: 의약품 오인 표현(치료·예방·개선·완화·재생·항염) 금지
- 미백·주름개선·자외선차단 등 기능성 효능 표방 금지(심사 안 받음)
- 최상급·배타(최고·1위·유일·100%·완벽·부작용 없음) 금지 / 위 금지어 금지
- 후기·데이터·효능을 창작하지 말 것. 내가 준 실제 자료만 사용
- 대가성(체험단·협찬)이면 "광고/유료광고" 표기 문구 포함
- 방어적 톤 금지 — 비판엔 "인정 + 개선 계획"으로
```

### 프롬프트 1 · 원본 1개 → 12벌 리퍼포징 (주력)
```
[A 브랜드 자산 블록]

[이번 원본 콘텐츠]
주제: 【예: 촉촉함이 아직 약한 이유와 개선 방향】
핵심 포인트: 1)__ 2)__ 3)__
확보 소재: 영상 2분 + 사진 20장(제형5·제품5·손5·배경5)

[요청] 아래 12개를 채널 톤·길이 정확히 지켜 만들어줘.
1) 인스타 릴스 대본 3개(각 20초, 첫 2초 후킹, 자막용 짧은 문장)
2) 인스타 피드 캡션 3개(첫 줄 후킹, 300자 내, 해시태그 10)
3) 캐러셀 5장(장별 헤드라인 15자+본문 40자)
4) 스토리 5장(각 20자, 마지막 행동유도 = 오픈채팅 유도)
5) 네이버 블로그 1편(2000자, 제목 3안, 소제목 5, 검색키워드 자연스럽게)
6) 스레드 3개(각 200자, 친근한 톤, 질문으로 끝)
7) 쇼츠 제목 3안 + 설명
8) 카카오채널 메시지 1건(80자, 클릭 유도)
9) 다음 콘텐츠 아이디어 3개

[가드 블록]
```

### 프롬프트 2 · 주간/월간 근황(비하인드) 포스트
```
[A 브랜드 자산 블록]
[이번 주 사실] 한 일:__ / 막힌 것:__ / 다음:__ / 사진: 손·비커·데이터(얼굴 없어도 '진짜 만든다')
[요청] 담백한 근황 포스트 1개(인스타 캡션 250자 + 블로그 단락 1개). 자랑 말고 과정·솔직함 위주. 오픈채팅 유도 1줄.
[가드 블록]
```

### 프롬프트 3 · "요청 → 검증 → 결정" (피드백 공개)
```
[A 브랜드 자산 블록]
[고객 요청] "__"(요약) / [검증] 관능(타깃 N명):__ · 실험:__(부작용:__) · 원가영향:±__원 / [결정] 반영 or 미반영 + 이유:__
[요청] 신뢰를 주는 회고 포스트 1개(인스타 + 블로그). "여러분 피드백으로 개선한다"는 메시지. 미반영도 이유를 정직하게.
[가드 블록]
```

### 프롬프트 4 · 약점 선(先)공개 포스트
```
[A 브랜드 자산 블록]
[공개할 약점] 촉촉함 아직 3.75(목표 4.0 미달) / [개선 방향]__(오일 증량은 산뜻함 USP와 상충해 지양, 수상 휴멕턴트 축으로)
[요청] 방어 아닌 인정 톤의 약점 공개 포스트. 마지막에 "어떤 상황에서 촉촉함이 아쉬운지" 질문으로 피드백 유도.
[가드 블록]
```

> 광고 소재 대량 생성은 완전가이드 **7-5**, 블로그 글감 24개는 **4-1**, 인스타 캡션 심화는 **5-5** 참고(여기 [A]·[가드] 블록을 붙여 쓰면 그대로 오후 톤).

## 6. 4주 시작 플랜 (포스팅 안 해본 사람용)

**1주차 — 세팅**
- [ ] 인스타 프로필 정비(한 줄 소개·오픈채팅 링크) + 카카오채널/오픈채팅 개설
- [ ] 스마트폰 촬영 세팅(자연광 창가) — 완전가이드 5-4

**2주차 — 첫 콘텐츠 데이**
- [ ] 원본 1개 촬영(포맷 ③ '비하인드' 추천 = 가장 쉬움) → 프롬프트 1로 12벌 → 2주치 예약
- [ ] 약점 선공개 포스트 1개(프롬프트 4)

**3주차 — 리듬**
- [ ] 정해둔 시간에만 DM·댓글 응대 + 후기 요청 시작(미니 50mL 체험)
- [ ] 블로그 장문 1편(콘텐츠 데이 원본 재활용)

**4주차 — 루프**
- [ ] '요청→검증→결정' 공개 1회(프롬프트 3)
- [ ] 지표 점검(소유채널 구독·후기 전환) — 팔로워 수 보지 말 것

## 7. 🚫 자동화·AI 하면 안 되는 것 (해자를 지킨다)

- **무엇을 말할지(콘텐츠의 목소리)** — 예약·제작은 AI, 메시지는 파운더.
- **DM·후기·피드백 응대** — 봇 금지, 사람이. (피드백=다음 버전의 씨앗)
- **불만·부정 후기** — 방어 대신 인정+계획, 반드시 사람.
- **후기·효능 창작** — 절대 금지(법규·신뢰 즉사).

> AI는 **제작 속도**를 올릴 뿐, **전략·목소리·관계**는 대신 못 한다.

## 8. 플랫폼 연결 (콘텐츠 원료는 여기서)

- **[브랜드 코어]** → [A] 자산 블록의 원천(톤·금지어·근거)
- **[개발 서사]** → '만든 이유·실패담' 원본
- **[관능·패널]** → 약점(3.75)·근거(4.5) 수치 = 정직한 콘텐츠 재료
- **[고객 접점·후기]** → 후기 리액션·동봉카드·재구매
- **[이미지 프롬프트 빌더]**(담백·자연광) → 배경·무드컷(제품·파운더는 실촬영)

> **마무리:** 포스팅을 "부담"이 아니라 **"월 1회 원본 → AI 12벌 → 예약"의 시스템**으로 바꾸면, 회사 병행으로도 주 2~3시간에 팬층이 쌓인다. 자동화로 번 시간은 **소통·피드백**에 몰아준다.
