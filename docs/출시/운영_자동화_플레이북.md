> **이 문서는 무엇인가**
> 개발이 끝나 제품을 만들고 **자사몰·스마트스토어에 판매**하는 1인 창업자가, **시간을 최대한 확보해
> "매출을 버는 행위"에 집중**하도록 — 운영의 어디를 자동화하고 어디를 사람이 지킬지, **도구·순서·템플릿**까지 정리.
>
> **대전제:** 이 브랜드의 무기는 **진정성·빠른 피드백**이다([팬베이스 전략](../사업/팬베이스_피드백루프_전략.md)).
> 그래서 원칙은 하나 — **잡무(반복 오버헤드)는 자동화, 해자(소통·피드백)는 사람.**
> ※ 아래 도구·가격·기능은 **예시이며 수시로 바뀝니다.** 도입 전 현행 스펙·요금·연동 가능 여부를 직접 확인하세요.

## 0. 대원칙 — "손·발"은 기계, "입·귀"는 당신

```
자동화 O (반복·규칙적·저부가)          사람 X (일회적·관계적·고부가)
├ 포장·발송·송장                       ├ 제품 피드백 응대(=다음 버전 씨앗)
├ 배송조회·FAQ 1차 응답                ├ 불만·부정후기 대응
├ 재구매 리마인더·쿠폰                 ├ 콘텐츠의 '목소리'
├ 리뷰 요청                            ├ 소유 채널(오픈채팅/뉴스레터) 대화
├ 매출 집계·재고 알림·정산            └ 팬과의 1:1
└ 콘텐츠 예약발행
```

> 💡 **판단 기준 한 줄:** "이걸 봇이 하면 팬이 실망하나?" → **예면 사람, 아니면 기계.**

## 1. 🚫 절대 자동화 금지 목록 (먼저 못 박기 — 이게 매출의 원천)

| 항목 | 왜 사람이어야 하나 |
|---|---|
| **제품 피드백 DM·후기 응대** | 피드백 루프 = 다음 버전의 씨앗. 봇이 받으면 개선 신호가 죽는다 |
| **불만·부정 후기 대응** | 진정성 승부처. 방어적/기계적 답변 1개가 캡처되어 확산 |
| **콘텐츠가 '무엇을 말할지'** | 예약발행(언제)은 OK, 메시지(무엇)는 파운더 |
| **소유 채널 대화** | 자동화하면 '팬'이 '수신 리스트'로 전락 |
| **약점 공개·"요청→검증→결정" 공개** | 브랜드 신뢰의 핵심 이벤트([팬베이스](../사업/팬베이스_피드백루프_전략.md) B템플릿) |

> 자동화로 **번 시간을 여기에 쏟는 것**이 이 플레이북의 진짜 목적입니다.

## 2. 라이프사이클 단계별 자동화

### 2-1. 상품 등록
- **콘텐츠 재사용:** brand-lab `상품 등록`(리스팅 자료)·`이미지 프롬프트`(제품컷)·`개발 서사`·`문구검사`·`고객 접점(뒷광고)` 산출물을 그대로 → 상세페이지·상품명·태그 초안.
- **동시 등록·재고 동기화(채널 2개↑일 때):** 자사몰+스마트스토어에 **같은 SKU**를 팔면 **재고 오버셀** 위험 → 통합관리로 재고·주문 싱크.
  - 예시(검증 필요): 플레이오토·사방넷·이지어드민·셀러오션 등.
- ⚠️ **초기(채널 1~2개·소량)엔 통합ERP는 과투자.** 스마트스토어 대량등록 엑셀 + 자사몰 개별 등록으로 충분. **재고만 수기로 맞추기.**

### 2-2. 주문 → 결제 → 배송 (⭐ 최대 시간 도둑)
- **송장 자동 출력:** 스마트스토어·자사몰 주문 → 택배사 연동 자동 송장(굿스플로 등).
- **풀필먼트(3PL) 위탁 = 핵심:** 재고를 물류사에 입고 → **주문 자동 출고**. 포장·발송·반품처리에서 해방.
  - 화장품 = 소형·경량 → 3PL 궁합 좋음.
  - 예시(검증 필요): 파스토·두손컴퍼니·콜로세움·딜리버드·품고·CJ 풀필먼트·쿠팡 로켓그로스.
- **판단:** 초기 500개는 **자가발송 + 송장 자동화**로 버티다, **주 발송량이 손을 아프게 하면 즉시 3PL 전환.** (시간 ROI가 가장 큰 스위치)

### 2-3. CS (반자동 — 봇 1차 + 사람 마무리)
- **FAQ 챗봇 1차 응답:** 배송기간·성분·사용법·반품/교환·재입고 → 자동. (채널톡·카카오 채널·스마트스토어 톡톡 자주묻는질문)
- **배송조회 자동:** 주문번호→송장 자동 안내.
- **AI 답변 초안 → 사람 검수·발송:** 반복 문의는 AI가 초안, 당신이 톤 다듬어 발송(속도+진정성 동시).
- 🚫 **제품 피드백성 문의는 봇 종료 후 사람으로 인계**(위 1번).

### 2-4. 재구매 / CRM (⭐ 매출 자동화의 핵심)
화장품 = **재구매가 사업.** 로션 50mL 소진 주기 ≈ **4~6주** → 자동 시퀀스로 재구매를 '설계'한다.
- **카카오 알림톡/친구톡 시퀀스:** 구매후 안내 → 사용점검 → 소진시점 재구매 유도(§4 템플릿).
- **정기구독(subscription):** 자사몰에 소진주기 정기배송(카페24·아임웹 정기결제 앱). 재구매를 아예 '구독'으로.
- **세그먼트 자동 분기:** 첫구매 / 재구매 / 휴면 별 다른 메시지.
- 스마트스토어 **소식받기·톡톡 마케팅메시지**로 재유입.

### 2-5. 리뷰 수집 (커머스의 화폐 — 자동 요청 + 수동 큐레이션)
- **구매후 리뷰 요청 자동:** 배송완료 며칠 뒤 포토리뷰 요청 + 적립 쿠폰(알림톡/리뷰솔루션).
- 예시(검증 필요): 크리마 등 리뷰관리 / 스마트스토어 리뷰이벤트.
- 🙌 수집은 자동, **좋은 후기 큐레이션·감사 답글은 사람**(관계 강화).

### 2-6. 백오피스 (정산·재고·세무)
- **매출 대시보드:** 채널별 매출·정산 자동 집계(커머스 API → 구글시트, 또는 솔루션 리포트).
- **임계재고 알림:** 재고 N개 이하 자동 알림(오버셀·품절 방지).
- **정산→회계·세무:** 매출 자료 자동 취합 → 세무대행/장부. (부가세·종소세 대비)
- ⚠️ **개인사업자·통신판매업·화장품책임판매업** 등록 상태 점검은 [판매 전 등록 체크리스트](판매전_등록_체크리스트.md).

### 2-7. 콘텐츠 (예약은 자동, 목소리는 사람)
- 예약발행·리퍼포징 자동화([브랜딩·마케팅 가이드 2부](브랜딩_마케팅_완전가이드.md)). 메타 비즈니스 스위트 예약 등.
- 🚫 "무엇을 말할지"는 자동화 금지.

## 4. 카카오 알림톡 시퀀스 템플릿 (복붙 → 심사용 초안)

> ⚠️ 알림톡은 **템플릿 사전 심사** 필요. **정보성(거래 관련)**은 발송 자유, **광고성(쿠폰·재구매 유도)**은 **수신동의 + 야간(21~08시) 발송 제한 + (광고)표기**. 아래는 초안 — 심사·법규는 §6.

**D+0 · 구매 감사 + 사용법 (정보성)**
```
[오후] 주문해 주셔서 고맙습니다 🌿
산뜻 보습 로션이 곧 출발해요.

▪ 사용법: 세안 후 2~3펌프, 오후 당김 느낄 때 덧발라도 안 밀려요
▪ 성분·개발 이야기: (링크)
궁금한 점은 편하게 답장 주세요. (제가 직접 봅니다)
```

**D+14 · 사용 점검 + 피드백 요청 (정보성·관계형)**
```
[오후] 2주 정도 쓰셨네요, 어떠세요?
'산뜻함/촉촉함' 중 아쉬운 점이 있으면 한 줄 남겨주세요.
→ 여러분 피드백으로 다음 버전을 만듭니다. (요청→검증→반영을 공개해요)
```

**D+21 · 포토리뷰 요청 (정보성 + 소액 보상)**
```
[오후] 후기 한 줄이 큰 힘이 됩니다 🙏
포토리뷰 남겨주시면 다음 구매 적립 쿠폰을 드려요. (링크)
```

**D+35 · 재구매 리마인더 (광고성 — 수신동의 필요)**
```
(광고) [오후] 슬슬 로션이 바닥 보이지 않나요?
지금 재구매하면 5% + 무료배송. 끊기지 않게 미리 챙기세요 🌿
수신거부: (링크)
```

**정기구독 전환 (광고성)**
```
(광고) [오후] 매번 주문 귀찮으셨다면 — 6주마다 자동배송(정기구독) 어떠세요?
구독가 + 우선 신제품 체험. (링크)
```

> 💡 D+14 '피드백 요청'은 **자동 발송하되 답장은 사람이** 받습니다(자동화 O + 해자 유지의 모범). 소진주기(4~6주)는 실제 데이터로 보정하세요.

## 5. CS 반자동 — FAQ 봇 시나리오 + AI 초안 원칙

**챗봇 1차 자동 응답 항목**
- 배송 기간 / 배송 조회(주문번호→송장)
- 성분·전성분·알러젠(라벨 링크)
- 사용법·사용순서
- 반품/교환/환불 정책·방법
- 재입고 알림 신청

**봇 → 사람 인계 트리거(자동화 금지 영역으로 넘김)**
- "이 성분 저한테 맞을까요" / 사용 후 트러블 / 제품 개선 제안 / 불만·부정 → **즉시 사람.**

**AI 답변 초안 원칙**
- 반복 문의는 AI가 초안 → **당신이 톤(담백·정직) 다듬어 발송.**
- 금지어([문구검사], 브랜드코어 ⑧) 필터 통과분만. 질병·효능 표방 금지.

## 8. ⚖️ 법규 체크 (자동 메시지도 규제 대상)

- **알림톡/친구톡:** 정보성(거래) vs **광고성(쿠폰·재구매 유도)** 구분. 광고성은 **사전 수신동의 + 야간(21~08시) 발송 제한 + "(광고)" 표기 + 수신거부 수단**.
- **화장품 광고 문구:** 자동 메시지·상세페이지 모두 **질병 표방·과장 금지**([문구검사], [가이드 14부](브랜딩_마케팅_완전가이드.md)).
- **리뷰 이벤트·체험단:** 대가성이면 **뒷광고 표기**(경제적 이해관계).
- **개인정보:** 마케팅 수신동의·개인정보 처리방침, 통신판매업 신고·표시사항.
