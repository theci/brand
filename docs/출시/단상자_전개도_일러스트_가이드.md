# 단상자 전개도(dieline) 일러스트 가이드 — 업체와 같은 언어로 대화하기

> 상태: ✅ 최신 · 목적 = **단상자(2차 포장) 전개도를 일러스트에서 다루는 법 + 인쇄·후가공 업체와 소통하는 언어**를 연습.
> **프린터**: 삼성 SL-T1685W (A4 · 무한잉크) — 단상자는 **A4를 넘으므로 1:1 전량 출력은 불가**(§6). 집 출력은 구조 이해·패널 확인용.
> **함께 보기**: 🖨️ [라벨·패키지 시제출력 가이드](라벨_패키지_시제출력_가이드.md) · 🎨 [디자인 브리프] 페이지 · 🏢 [판매전 등록 체크리스트](판매전_등록_체크리스트.md)

> ⚠️ **핵심 관점:** 실무에서 정밀 전개도(칼선·두께 보정·접힘 여유)는 **업체가 목형(die)으로 만들어 준다.** 우리가 하는 일 = ① 구조·용어 이해 → ② 업체 칼선 파일 위에 **아트웍만** 얹기 → ③ **정확히 질문·발주**하기. 이 문서는 그 연습이다.

---

## 0. 대원칙 — "그리는 사람"이 아니라 "얹고 발주하는 사람"

| 우리가 할 일 ✅ | 업체가 할 일(맡긴다) |
|---|---|
| 지기구조(박스 형태)·치수 결정 | **목형(칼선) 제작** — 종이 두께 보정·접힘 여유 |
| 업체 칼선 위에 **아트웍·표시사항** 배치 | 오시(누름선)·도무송(재단) 가공 |
| 인쇄 규격(CMYK·별색·도련) 맞춰 파일 넘기기 | 인쇄·후가공·접착·조립 |
| **정확한 질문/발주서** 작성 | 교정쇄(샘플) 제공 |

> 💡 집에서 하는 전개도는 **"구조를 몸으로 이해하고, 업체와 대화가 되게 하는 연습"**. 1:1 양산 칼선을 손으로 완벽히 그릴 필요는 없다.

## 1. 먼저 용어 — 업체가 쓰는 말 (이것만 알면 대화가 된다)

| 용어 | 뜻 | 일러스트에서 |
|---|---|---|
| **지기구조** | 박스의 형태·구조 | 어떤 상자 타입을 쓸지(§2) |
| **칼선 / 목형(die)** | 재단(자르는) 선 / 그 물리 칼틀 | **별색 레이어**로 분리(§4) |
| **도무송 / 톰슨** | 칼선대로 눌러 자르는 가공(die-cut) | — (업체 가공) |
| **오시(누름선) / 크리스** | 접히는 자리에 누름 자국 | 칼선과 **다른 선 스타일**로 구분 |
| **풀칠탭 / 사이드심** | 옆면 접착 날개 | 전개도 한쪽 끝 날개 |
| **턱(tuck) / 더스트플랩** | 뚜껑 끼움날개 / 좌우 먼지막이 날개 | 상·하 마감 구조 |
| **도련(bleed)** | 재단선 밖 여유 인쇄 | 사방 3mm |
| **별색(spot) / 4도(CMYK)** | 특정 지정색 / 일반 인쇄 | 색 지정 방식 |
| **평량(g/m²)** | 종이 두께·무게 | 종이 선택(§3) |
| **후가공** | 코팅·박·형압·도무송 등 | 지정만, 가공은 업체 |
| **교정쇄 / 백목업** | 실사 샘플 / 무지 접이 샘플 | 양산 전 확인 |

## 2. 지기구조 고르기 — 200mL 병엔 '턱 엔드'가 표준

에어리스 200mL(지름 55 · 높이 174)는 **세워 넣는 세로 상자**가 자연스럽다. 대표 구조:

| 구조 | 특징 | 추천도 |
|---|---|---|
| **리버스 턱 엔드(RTE)** | 위·아래 뚜껑이 반대 방향 끼움. 가장 흔함·저렴 | ⭐ **1순위**(단품) |
| 스트레이트 턱 엔드(STE) | 위·아래 같은 방향 끼움. 앞면 깔끔 | 대안 |
| 락바텀(auto-lock) | 바닥 자동잠금, 무거운 내용물 | 병이 무거우면 |
| 슬리브 | 밴드형 끼움(무접착) | 미니멀·친환경 감성 |

> **추천:** 단품은 **리버스 턱 엔드**. 담백/친환경 서사를 강조하려면 **슬리브**나 아예 **무박스**도 유효(초기 500개엔 무박스 권장 — [라벨 가이드] 흐름).

## 3. 종이(평량)·후가공 — 담백 컨셉 기준

- **평량:** 단상자는 강성 필요 → **아트지/스노우지 300~350g/m²** 또는 **크라프트 300g**.
- **컨셉 궁합(가공하지 않은 파운더):**
  - **무광 스노우지 + 무광 라미네이팅** = 차분·정직(추천).
  - **크라프트지 무코팅** = 담백·친환경 서사 강하게.
  - ❌ 유광 코팅·금박·펄 = 럭셔리 톤 → 컨셉과 충돌(브랜드 금지어 축과 동일).
- **후가공 최소:** 단색 인쇄 + 무광 코팅 정도. 포인트는 **형압(엠보/디보싱)** 로고 하나면 충분(박·유광보다 담백).

## 4. 일러스트레이터 — 칼선/오시/아트웍 분리 (핵심 기술)

> 업체 칼선 파일이 있으면 그 위에 **아트웍 레이어만** 작업. 연습용으로 직접 만들 땐 아래대로.

### 4-1. 새 문서
| 항목 | 값 |
|---|---|
| 프로파일 / 단위 | 인쇄 / mm |
| 크기 | 전개도 전체 크기(§5 계산) |
| 도련 | 사방 **3mm** |
| 색상 모드 | **CMYK** · 래스터효과 300ppi |

### 4-2. 레이어 (아래→위)
1. `artwork` — 배경·그래픽·이미지
2. `text-legal` — 표시사항 텍스트(K 단색)
3. `오시(crease)` — 접는선
4. `칼선(die)` — 재단선  ← **맨 위, 인쇄 안 되는 안내/별색**

### 4-3. 칼선·오시 선 스타일 (업체 표준)
- **별색 스와치 2개 생성**: 색상 견본 패널 > 새 견본 > **색상 유형 = 별색(Spot)**.
  - `Die`(칼선) — 예: 마젠타 100% 별색, **선(획)만** 0.25pt.
  - `Crease`(오시) — 예: 시안 100% 별색, **점선(dashed)** 0.25pt.
- 두 선 모두 **획에 '중복 인쇄(Overprint Stroke)'** 체크(속성 패널) → 아트웍을 안 파먹음.
- 칼선/오시는 **면(칠) 없이 선만**. 닫힌 패스로.
- 레이어 이름을 `Die`, `Crease`로 정확히 → 업체가 바로 인식.

### 4-4. 안전여백
- 접는선·재단선에서 **안쪽 3~5mm** 안으로 텍스트·로고. 접힘/재단 오차 대비.
- 바코드·표시사항은 **한 면(주로 뒷면·바닥)** 에 몰아 배치.

### 4-5. 표시사항(법정)
- 화장품 표시사항은 **소비자가 보는 포장(1차 또는 2차)** 에 있으면 된다. 단상자에 넣을지, 병 라벨에 넣을지 **중복·누락 없게** 정리.
- [라벨] 페이지 출력을 정본으로 그대로 타이핑(임의 수정 금지).

### 4-6. 저장
- 편집 원본 .ai / 넘길 파일은 **사본에서 문자 윤곽선** + **PDF(별색 살린 PDF/X-4)**.

## 5. 치수 — 병 → 상자 → 전개도 (연습 계산)

> 정밀 보정은 업체 몫. 여기선 **대략 크기·A4 초과 여부**를 감 잡는 용도.

1. **상자 내경** = 병 외경 + 여유(clearance) 2~3mm.
   - 폭 L ≈ 폭 W ≈ 55 + 3 = **58mm**(정사각 바닥), 높이 H ≈ 174 + 5 = **~180mm**.
2. **전개도 대략 크기**(리버스 턱 엔드):
   - 가로 ≈ 2×(L+W) + 풀칠탭(≈15) = 2×(58+58)+15 ≈ **247mm**
   - 세로 ≈ H + 상·하 (턱+더스트플랩) ≈ 180 + 2×50 ≈ **~280mm**
3. ⇒ **약 247 × 280mm → A4(210×297) 폭 초과.** 집 프린터 **1:1 전량 출력 불가**(§6).

> 손 계산이 번거로우면 **무료 전개도 생성기**(예: templatemaker 류)나 업체 **표준 목형 템플릿**을 받아 치수만 넣는다.

## 5-b. 연습용 전개도 파일 (바로 열어 쓰기) ✅

이 폴더에 병 규격에 맞춘 **리버스 턱 엔드 칼선 파일**을 넣어뒀다:

- **`단상자_전개도_연습_RTE_58x58x180.svg`** — 내경 58×58×180mm(200mL 병 55×174 + 여유), 전체 247×296mm.
- 일러스트에서 **파일 > 열기**. 레이어 `Cut`(빨강 재단)·`Crease`(파랑 점선 오시)·`Labels` 분리됨.
- 쓰는 법:
  1. `Labels` 숨김, `artwork` 레이어 새로 만들어 그 위에 디자인·표시사항 얹기.
  2. 출력해 **빨강=가위 재단, 파랑 점선=접기**. 오시선은 안 쓰는 볼펜/뼈칼로 살짝 눌러 접으면 각이 산다.
  3. 접이 순서: 옆면 더스트플랩 먼저 → 앞/뒤 턱 끼움. 풀칠탭으로 옆면 접착.
- ⚠️ **이건 연습용 근사치**다. 종이 두께 보정·정밀 여유는 양산 시 **업체 목형**으로 확정(§0·§8).

## 6. 집에서 연습 출력 (SL-T1685W · A4 한계 인정)

단상자는 A4를 넘으니 **1:1 전체는 못 뽑는다.** 대신:

| 방법 | 용도 |
|---|---|
| **축소 인쇄(예 60~70%)** 로 A4에 전체 전개도 | 구조·접이 순서 **이해·연습**(1:1 아님 명시) |
| **패널 1~2면만 1:1** 로 A4 출력 | 앞면 디자인·표시사항 **가독성·비율** 확인 |
| **A3는 인쇄소/출력소**에서 1장 | 1:1 전개도 접이 리허설 |
| 업체 **백목업(무지 접이 샘플)** 요청 | 실제 구조·크기 감(가장 정확) |

- 축소본이라도 **오시선 눌러 접어** 보면 뚜껑 끼움·풀칠 순서가 손에 익는다 → 업체 대화가 쉬워진다.
- 출력 설정은 [라벨 가이드 §5]와 동일(배율만 축소/100% 목적에 맞게, 색관리 한쪽만).

## 7. 업체에 넘기기 전 최종 체크

- [ ] **칼선(Die)·오시(Crease)** 별색 레이어 분리, 선만(칠 없음), 중복인쇄 체크
- [ ] 레이어명 `Die`/`Crease`/`artwork` 명확
- [ ] **CMYK**(별색 쓰면 별색 지정 명시) · 이미지 300dpi · 도련 3mm
- [ ] 폰트 **윤곽선화** 또는 동봉
- [ ] 표시사항 [라벨] 페이지와 1:1 대조(중복·누락 없음)
- [ ] **PDF/X-4**(별색 유지)로 저장
- [ ] 후가공 지정(무광 코팅/형압 위치) 별도 표기
- [ ] **교정쇄(실사) + 백목업** 요청

## 8. 업체 대화 체크리스트 — 이 질문들을 하면 '아는 사람'이 된다

**보낼 때 함께 전달:**
- 지기구조(예: 리버스 턱 엔드) · 내용물(200mL 에어리스 병, 55×174)
- 수량(초도 예: 500·1,000·3,000) · 종이(예: 무광 스노우지 300g) · 도수(예: 1도 또는 CMYK)
- 후가공(무광 코팅 + 로고 형압) · 납기 희망일

**물어볼 것:**
1. **목형(칼선) 템플릿** 파일 주실 수 있나요? (아트웍을 그 위에 얹겠습니다)
2. 이 구조·종이의 **최소수량(MOQ)** 과 **단가**는요?
3. **목형비(die 제작비)** 는 별도인가요? (초판만 발생)
4. **도련·안전여백** 규격 얼마로 드릴까요?
5. **별색**으로 할까요, **CMYK**로 할까요? (담백 1도면 별색이 저렴할 수 있음)
6. **교정쇄(실사)·백목업** 가능한가요? 비용·납기는?
7. 후가공(코팅/형압) 가능 범위와 추가 단가?
8. 파일 포맷은 **PDF/X-4 + 윤곽선** 로 드리면 되나요?

> 💡 "목형/칼선/오시/도련/별색/MOQ" 여섯 단어만 정확히 쓰면 업체는 **초보로 안 봅니다.**

## 9. 플랫폼 연결

- **[디자인 브리프]** §3 표시사항·§5 비주얼 코드·§6 프롬프트 = 단상자 앞면 아트웍·표시사항의 원천.
- 단상자 **앞면 키비주얼**은 [이미지 프롬프트 빌더](담백·자연광 기본)로 생성 → 4-1 아트웍 레이어에 배치.
- 표시사항 정본 = **[라벨] 페이지** 출력(병 라벨과 중복·누락 조율).

---

> **한 줄:** 단상자는 **직접 완벽히 그리는 게 목표가 아니라, 업체 칼선 위에 얹고 같은 언어로 발주하는 것**이 목표다. 구조·용어·질문 리스트를 손에 익히면, 첫 통화부터 대화가 된다. 색·구조 최종 확인은 **교정쇄·백목업**으로.
