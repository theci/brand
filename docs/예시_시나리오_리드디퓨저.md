# 예시 시나리오 ③ — 리드 디퓨저 하나를 처음부터 끝까지 · **화장품이 아닌 제품편**

이 문서는 [`예시_시나리오.md`](예시_시나리오.md)(샴푸바)·[`예시_시나리오_수분로션.md`](예시_시나리오_수분로션.md)(로션)의 세 번째 편입니다.
앞의 둘은 **화장품(화장품법)**이었지만, 이번엔 **화장품이 아닌 제품 — 방향제(화학제품안전법)**입니다.
"제품을 뭐라고 부르느냐가 비용을 수백만원 바꾼다"는 이 플랫폼의 핵심을 실제로 보여줍니다.

> 명령은 모두 이 저장소에서 **그대로 실행됩니다.** 결과는 실제로 실행해 얻은 값입니다.
> 이 결과는 1차 스크리닝이며 법적 판단이 아닙니다. 출시 전 관할 기관(환경부·KTR) 확인이 필요합니다.

**만들 제품**: 라벤더 리드 디퓨저 (방향제·지속방출형, 200㎖) · 목표 판매가 25,000원 · 초도 1,000개

### 왜 이 제품인가 — 화장품과 무엇이 근본적으로 다른가

| 구분 | 화장품(샴푸바·로션) | **방향제(이 문서)** |
|---|---|---|
| 적용 법 | 화장품법 | **화학제품안전법(생활화학제품)** |
| 등록/신고 | 영업자 등록 **1회** | **제품·배합마다 신고** |
| SKU 추가 비용 | **0원** | **품목마다 시험비**(방향제 지속방출형 27만원) |
| 갱신 | 없음 | **3년마다** |
| 라벨 | 전성분 표시 | **신고번호·안전기준 적합확인·어린이보호포장** 등 (완전히 다름) |
| `label` 명령 | 사용 O | **사용 X** (화장품 전용) → 레짐 검증 사용 |

> **"같은 라벤더 향인데, 몸에 뿌리면 향수(화장품), 공간에 두면 디퓨저(방향제)다. 그런데 이 둘의 규제비용이 하늘과 땅 차이다."**
> 이걸 STEP 0에서 숫자로 확인하는 게 이 시나리오의 핵심입니다.

> 한 줄 요약: "공간(space)에 쓰는, 향(fragrance) 목적, 지속방출(sustained_release) 제형."

> **"SKU 10종 기준 530만원 차이다. 이유는 방향제는 품목마다 27만원짜리 신고 시험을 해야 하고 3년마다 갱신하기 때문."**

**이 시나리오에서는 학습을 위해 "방향제(디퓨저)"로 진행합니다.** 하지만 실제 창업이라면 이 계산을 보고 전략을 다시 생각하게 됩니다:
- 리드 디퓨저는 "공간 방향" 제품이라 방향제(화학제품안전법)가 자연스럽습니다.
- 만약 "손목에도 바르는 향" 컨셉이라면 향수(화장품)로 포지셔닝해 규제비를 아낄 여지가 있습니다 — **단, 실제 분류는 관할 기관이 결정**하므로 서면 질의 필수.


### 📚 리드 디퓨저 원료 구성 — 자리별로 왜 넣는가

디퓨저는 구조가 단순합니다. **향료 + 그 향을 리드로 실어 나르는 용제**가 전부입니다.

| 역할(자리) | 이 처방의 원료 | 왜 필요한가 |
|---|---|---|
| **향료(주인공)** | 라벤더오일 20% | 실제로 퍼질 향. 디퓨저는 향료 함량이 15~30%로 화장품보다 훨씬 높음. |
| **베이스 용제** | 디프로필렌글라이콜(DPG) 63% | 향을 녹이고 **리드를 타고 천천히 올라가** 상단에서 증발. 저취·저휘발이라 향을 방해 안 함. |
| **확산 보조** | 이소프로필미리스테이트(IPM) 5% | 향이 리드를 **잘 타고 오르게**(모세관 상승 촉진). 발향·확산을 도움. |
| **점도 조절/발향** | 에탄올 12% | 점도를 낮춰 리드 흡수를 도움. 초기 발향(throw)을 키움. |

> **"핵심 원리는 모세관 현상이다. 리드(갈대·라탄 막대)의 미세한 구멍으로 액체가 빨려 올라가고, 막대 윗부분에서 향이 공기 중으로 증발한다. DPG는 이 '빨려 올라가는 속도'를 적당히 늦춰 향이 오래가게 한다."**

---

### ❓ 디퓨저에도 '화장품용 등급(cosmetic grade)'이 필요한가요?

디퓨저는 **피부에 바르지 않는** 공간용 제품이라, 엄밀히는 화장품용 등급이 아니어도 됩니다(캔들·디퓨저용 향료도 사용 가능).
다만 이 도구의 `cosmetic_grade`/CoA 플래그는 화장품 관점이라, 방향제에선 대신 **화학제품안전법의 함유금지·제한물질**(STEP 5) 기준으로 원료를 검토해야 합니다.

> **"화장품이면 '화장품용 등급인가'를 보지만, 방향제면 '안전확인대상 고시의 금지·제한물질에 걸리나'를 봐야 한다. 보는 규제 자체가 다르다."**

## STEP 2 — 처방 작성 (`formulas/reed-diffuser/v1.yaml`)

> **"디퓨저는 가열이 필요 없다. 그냥 상온에서 용제에 향을 녹이면 끝이다. 에멀전처럼 상을 여러 개 나눌 필요도 없다."**

```yaml
product: 라벤더 리드 디퓨저
slug: reed-diffuser
version: 1
regime: chemical_safety        # ★화장품 아님! STEP 0에서 나온 레짐을 그대로
product_category: 방향제_지속방출형   # fees.yaml 품목 코드 (리드=지속 방출)
product_type: leave_on         # 방향제엔 의미 없지만 코어 필수 필드라 placeholder
status: 개발중
base_batch_g: 200
phases:
  - name: A (상온 블렌딩)
    process: 상온에서 용제(DPG·IPM·에탄올)에 향료를 넣고 맑아질 때까지 저어 혼합
    ingredients:
      - { id: dpg, percent: 63.0 }
      - { id: ethanol, percent: 12.0 }
      - { id: ipm, percent: 5.0 }
      - { id: lavender-eo, percent: 20.0 }
packaging:
  - { id: diffuser-bottle-200ml, qty_per_unit: 1 }
fill_volume_ml: 200
```

### ❓ `regime: chemical_safety`와 `product_category`는 왜 둘 다 필요한가요?

- **`regime`** = 어떤 **법**인가 (화장품법 vs 화학제품안전법). 라벨·비용 규칙 전체를 결정.
- **`product_category`** = 그 법 안에서 어떤 **세부 품목**인가. 화학제품안전법은 품목마다 시험비가 달라서(방향제 지속방출형 27만 vs 분사형 58.5만), **정확한 품목 코드**가 있어야 비용을 계산합니다.

> **"화장품은 품목 세분류가 비용에 영향을 안 줘서 `product_category`가 없어도 됐다. 방향제는 품목마다 돈이 달라서 반드시 필요하다."**
> 품목 코드 목록은 `data/regulatory/chemical_safety/fees.yaml`에 있습니다.

## STEP 3 — DOE 스크리닝: 발향·지속·확산의 트레이드오프 (`doe analyze`)

> **"향료를 많이 넣으면 향은 세지겠지만 빨리 소진되지 않을까? DPG를 늘리면 오래갈까? 감이 아니라 실험으로 보자."**

```bash
uv run brandlab doe analyze experiments/doe/reed-diffuser-screening.yaml
```
```
주효과 — 디퓨저 스크리닝
  인자        발향강도  지속력  확산속도
  fragrance    +2.00   -1.00    +0.00
  dpg          -1.00   +2.00    +0.00
  ipm          +0.00   +0.00    +2.00
```

> **해석:**
> - **향료↑ → 발향강도 +2, 하지만 지속력 −1** (세지만 빨리 소진). 트레이드오프.
> - **DPG↑ → 지속력 +2, 발향강도 −1** (은은하고 오래감).
> - **IPM↑ → 확산속도 +2** (리드를 빨리 타고 올라 초기 확산이 빠름).
>
> **"강하고 짧게 갈지(향료↑), 은은하고 오래 갈지(DPG↑)를 고르는 문제구나. 나는 오래가는 쪽을 선호하니 DPG를 넉넉히 두자."**

## STEP 5 — 규제 검증·표시기준 (화장품과 다른 방식!)

> ⚠️ **"방향제는 `label` 명령을 쓰면 안 된다. 그건 화장품 전성분 전용이다."**
> 방향제는 **레짐(chemical_safety)의 검증·표시기준**을 사용합니다. 아직 전용 CLI가 없어 파이썬으로 확인합니다.

```bash
uv run python -c "
from brandlab.loader import BrandLab
from brandlab.regimes import regime_for
lab = BrandLab.load()
f = next(x for x in lab.formulas if x.slug=='reed-diffuser')
r = regime_for(f)
print('레짐:', r.law_name)
print('SKU 확장비:', format(r.sku_expansion_cost(f),','), '| 갱신:', r.renewal_period_years(f), '년 | 시험기간:', r.lead_time_days(f), '일')
for fd in r.validate(f): print('[%s]' % fd.level, fd.message)
for it in r.label_spec(f).items: print(' -', it.label)
"
```

### ❓ 왜 `label`(화장품)과 레짐 검증이 나뉘어 있나요?

법이 다르면 **표시 항목 자체가 다르기 때문**입니다. 화장품은 "전성분을 함량 순으로", 방향제는 "신고번호·안전기준 적합확인·어린이보호포장 여부". 그래서 이 도구는 제품의 `regime`에 따라 서로 다른 규칙을 적용합니다. `label` 명령은 화장품 전용이고, 방향제는 레짐 객체(`regime_for(f)`)로 검증합니다.

✅ **게이트:** 함유금지·제한물질 데이터를 채워 실제 대조. 신고번호 자리·안전기준 표시를 라벨 시안에 반영.

## STEP 6 — 원가·손익 (`cost`) — "두 개의 비용 축"을 구분하라

```bash
uv run brandlab cost reed-diffuser v1 --units 1000 --price 25000
```
```
개당 원가: 7,403원 (원료 4,903 + 부자재 2,500)
공헌이익 4,304원 · 마진율(실매출) 18.9%
목표마진 40% 최소판매가: 44,504원
손익분기 수량: 1,721개
총 선투입 자본: 7,403,440원 (원료 4,903,440 + 부자재 2,500,000)
```

> **"원료비가 4,903원?! 로션은 444원이었는데 10배가 넘네."**
> **"디퓨저는 향료가 20%나 들어가는데 라벤더오일이 비싸서(kg당 12만원) 그렇다. 향료가 원가를 지배한다."**
> **"25,000원에 팔면 마진이 18.9%밖에 안 되고, 손익분기가 1,721개다 — 초도 1,000개로는 원금 회수도 안 된다. 목표 마진(40%)을 맞추려면 44,504원을 받거나 향료를 줄여야 한다."**

⚠️ **아주 중요한 구분 — 비용은 두 종류다:**

| 비용 축 | 명령 | 이 제품 | 성격 |
|---|---|---|---|
| **제조원가·손익** | `cost` | 개당 7,403원 · 선투입 740만 | 레짐 무관(어떤 법이든 동일) |
| **규제비용** | `advise`/레짐 | 신고 시험비 27만/품목 + 3년 갱신 | 레짐에 따라 천지 차 |

> **"`cost`는 '만드는 돈'이고, `advise`는 '허가받는 돈'이다. 방향제는 둘 다 든다. 화장품이었다면 규제비는 등록 1회 10만원으로 끝났을 것."**

✅ **게이트:** 제조 마진 + 규제비(SKU 27만·3년 갱신)를 **합쳐서** 사업성이 나오는가?

## STEP 9 — 공장 협의: 방향제 특화 주의점

OEM/ODM 선택·공장 찾기·NDA·견적·계약·사기 예방 등 **공통 절차는 [`예시_시나리오.md`](예시_시나리오.md) STEP 10을 그대로 따르세요.** 여기서는 **방향제(화학제품안전법)에서만 다른 점**만 정리합니다.

### 9-1. 신고는 누가 하나 — 이게 제일 다르다

- 화장품은 "영업자 등록" 한 번이면 SKU 자유였지만, **방향제는 제품(배합)마다 안전확인대상 신고**가 필요합니다.
- 신고 주체·시험 의뢰를 **공장이 대행하는지, 내가 KTR에 직접 하는지** 계약 전에 명확히 하세요.
- **신고번호가 나와야 판매 가능**합니다. 신고 없이 팔면 화학제품안전법 위반.

```
공장/시험기관에 확인할 것:
□ 안전확인대상 신고 대행 여부 (공장이 해주나, 내가 하나)
□ 시험 항목·비용 (품목: 방향제 지속방출형 기준)
□ 신고번호 취득 예상 기간 (시험 약 9영업일 + 신고 처리)
□ 함유금지·제한물질 저촉 여부 사전 검토
□ 3년 후 갱신 시 재시험 비용
```

### 9-2. 3년 갱신을 놓치지 마라

> **"화장품과 달리 방향제는 3년마다 갱신이다. SKU가 늘면 갱신도 품목마다 돌아온다."**
> 신고일 기준 갱신 예정일을 캘린더에 등록하세요. (플랫폼 확장 시 P12 포트폴리오의 `regulatory_calendar`가 이 일정을 관리합니다.)

### 9-3. 인화성·표시 — 에탄올 들어간 방향제

- 이 처방은 에탄올 12%로 **인화성**이 있습니다. "화기 주의" 등 사용상 주의사항 표시가 필요합니다.
- 운송·보관도 인화성 기준을 따릅니다. 공장·택배사에 확인하세요.
