## 📌 문서 관리 규칙 (새로 만들거나 고칠 때)

플랫폼·제품이 계속 늘어나도 `docs/` 가 다시 뒤섞이지 않도록, 아래 4가지만 지키면 됩니다.

### 1. 새 문서는 "목적"으로 폴더를 정한다
| 문서 성격 | 넣을 폴더 |
|---|---|
| 새 **제품**의 사업 시나리오·전략 | `사업/` |
| 손으로 만드는 **제조·장비·원료** 실무 | `홈랩/` |
| **OEM·등록·법무·마케팅** 실행물 | `출시/` |
| 앱 **사용법·기능 설계·확장 기획** | `플랫폼/` |
| 다른 제품군 **데모·참고**(주력 아님) | `예시_시나리오/` |
| 학습 **커리큘럼** | `커리큘럼/` |

### 2. 새 제품이 늘어날 때 (가장 자주 생기는 케이스)
- 시나리오: `사업/사업_시나리오_<제품명>.md`
- 이미지: `img/<제품명>/` 폴더를 새로 만들고 그 안에 캡처 (+ 선택: `img/<제품명>/README.md` 캡처 체크리스트)
- 문서에서 이미지 링크는 **`../img/<제품명>/파일.png`** (문서가 하위 폴더에 있으므로 `../` 로 나감)
- 허브([사업_시나리오_산뜻보습로션.md](사업/사업_시나리오_산뜻보습로션.md))의 **📚 문서 지도**와 이 **README 폴더 지도**에 한 줄 추가

### 3. "과거 vs 최신" 혼재를 막는 상태 표기
각 문서 **맨 위**에 한 줄 상태선을 두면, 열지 않고도 최신인지 안다:
```
> 상태: ✅ 최신 · 최종수정 2026-09-09 · 대상: 산뜻보습로션 v2
```
- `✅ 최신` / `🟡 개정중` / `📦 보관(구버전)` 3단계면 충분.
- 더 이상 안 쓰는 문서는 **지우지 말고** `상태: 📦 보관` 으로 바꾸고, 대체 문서를 `→ 대체: <링크>` 로 남긴다.
- 파일을 옮길 땐 **문서 간 상대경로 링크가 깨지므로**, 옮긴 뒤 반드시 링크 점검(아래 4).

### 4. 옮기거나 새로 링크한 뒤엔 깨진 링크 검사
`docs/` 어디서든 실행 (없는 대상 링크·이미지를 찾아준다):
```bash
python3 - <<'PY'
import re, posixpath; from pathlib import Path
R=Path("docs"); L=re.compile(r'!?\[[^\]]*\]\((<[^>]+>|[^)\s]+)[^)]*\)'); bad=0
for md in R.rglob("*.md"):
    rel=md.relative_to(Path(".")).as_posix()
    for m in L.finditer(md.read_text(encoding="utf-8")):
        d=m.group(1); d=d[1:-1] if d.startswith("<") else d
        if d.startswith(("http","mailto:","#")): continue
        d=d.split("#",1)[0]
        if not d: continue
        t=posixpath.normpath(posixpath.join(posixpath.dirname(rel),d))
        if not Path(t).exists(): print("❌",rel,"->",d); bad+=1
print("깨진 링크:",bad)
PY
```

> ⚠️ 이 인덱스는 사람이 갱신합니다. 문서를 추가/이동하면 **이 파일의 폴더 지도**도 함께 고쳐 주세요.
