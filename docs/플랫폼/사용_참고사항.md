# brand-lab 사용 시 참고사항

> 이 문서는 플랫폼을 **실제로 쓸 때** 반드시 기억할 점을 모은 것입니다.
> 기능 설명이 아니라 "믿으면 안 되는 것 / 바꿔야 하는 것 / 확인해야 하는 것"입니다.

---

## 0. 대전제 — 이 도구는 법적 판단이 아니다

라벨·알러젠·규정·문구·레짐 판정은 **전부 1차 스크리닝**입니다. 통과했다고 적법이 아닙니다.
출시·신고 전 반드시 **식약처 / 환경부·한국환경산업기술원(KTR) / 지방식약청**에 서면으로 확인하세요.
제품 분류(화장품이냐 생활화학제품이냐 등)는 최종적으로 **관할 기관이 결정**합니다.

---

## 1. "예시값"으로 채워둔 데이터 — 쓰기 전에 실제 값으로 교체할 것

플랫폼이 돌아가는 걸 보여주려고 넣은 값이 많습니다. **실제 판단에 쓰기 전 교체 필수:**

| 데이터 | 위치 | 주의 |
|---|---|---|
| 원료 단가·밀도 | `data/ingredients.yaml` (`price_per_kg`, `density`) | 견적·성적서 값으로 교체 |
| 원료 CoA 보유·등급 | 〃 (`has_coa`, `cosmetic_grade`) | 실제 성적서 확보 여부로 갱신. **기본 `has_coa: false`(안전측)** |
| 알러젠 함량% | 〃 (`allergens[].percent`) | 공급처 **GC 성적서** 값으로 교체 (라벤더 30% 등은 예시) |
| 포장재 단가·MOQ | `data/packaging.yaml` | 실제 견적으로 교체 |
| 손익 가정 | `data/config.yaml` (`economics`) | 채널 수수료율·배송비·반품률·부가세 실제값 |
| 향료 IFRA 한도 | `data/aroma_materials.yaml` (`ifra_한도_퍼센트`) | **IFRA Standards 원문**으로 교체 |
| 알러젠·배합한도·표시규정 | `data/regulatory/cosmetics/*.yaml` | 식약처 고시 원문 대조 |
| 광고 금지표현 | `data/regulatory/cosmetics/ad_terms.yaml` | 예시 10건뿐. **나머지는 직접 채워야** 함 |
| 레짐 진입비용·기간 | `data/regulatory/<regime>/regime.yaml` | KTR 공시값도 제품 사양별로 다름 → 신고 전 확인 |

**규칙:** 규제 수치는 코드가 아니라 전부 YAML에 있습니다. 값을 바꾸면 코드 수정 없이 반영됩니다.
각 규제 파일에는 `last_updated`와 `source_url`을 반드시 갱신하세요.

---

## 2. 규제 데이터는 시간이 지나면 틀린다

- 규제 YAML에 `last_updated`가 있고, **180일이 지나면 경고**가 뜹니다(`freshness_check`).
- 경고가 뜨면 무시하지 말고 고시 원문을 다시 확인하고 날짜를 갱신하세요. 법은 바뀝니다.
- KTR 시험비용·기간(레짐 데이터)은 2026-08 기준 공시값이며, **품목 분류와 실제 적용은 제품마다 다릅니다.**

---

## 3. 제품 카테고리(레짐)가 돈을 결정한다

이게 이 플랫폼의 핵심 통찰입니다.

- **화장품법**(샴푸·클렌징·립밤·오일·화장비누·향수): 영업자 등록 **1회 10만원**, 이후 **SKU 몇 개든 추가 규제비용 0원**.
- **화학제품안전법**(탈취제·방향제·초): **품목·배합마다 시험비**(21~58.5만원) + **3년마다 갱신**. SKU를 늘릴 때마다 돈이 나감. (P10에서 지원 예정)
- **빼야 하는 것**: 섬유유연제(197만원)·세탁세제(105만원) → 대량물류·가격경쟁 시장, 1인이 이길 구조 아님.
- **절대 안 되는 것**: 살균·살충·방충·기피(**살생물제 = 승인제, 약 12개월, 미승인 시 제조·판매 전면 금지**), 치약·손소독제(**의약외품 = 약사법**). → 코드가 `validate`에서 **error로 거부**합니다.

같은 향이라도 "향수(화장품)"로 내면 등록 1회로 무제한, "디퓨저(방향제)"로 내면 향마다 27만원+갱신.
**이름을 뭐라고 붙이느냐가 총비용을 수백만원 바꿉니다.** (이 비교를 자동화하는 게 P11 RegimeAdvisor.)

## 4. 계산에 들어간 단순화 가정 (알고 써야 함)

- **알러젠 표기 임계값**: "초과"(`>`)로 판정. 정확히 0.01%는 표기 불필요로 처리(고시 문구 기준). 보수적으로 "이상"을 원하면 바꿔야 함.
- **손익 모델**: 실매출=판매가÷(1+부가세), 수수료는 판매가 기준, 반품비=반품률×(배송비+원가) 손실 가정(리셀 불가·보수적). 마진율(net)=공헌이익÷실매출.
- **원가 부피→질량**: 처방%를 부피에 적용 후 밀도로 g 환산. **비누(net_weight_g)는 질량 기준.**
- **비누 전성분**: CP 비누는 완제품이 비누화물(Sodium Olivate 등)이라 투입원료(NaOH+오일) 목록을 **그대로 라벨로 쓰면 안 됨** → 경고가 뜸.
- **조향 blend**: `parts`는 원액(neat) 기준 비율. 10% 희석액 계량은 자동 환산.
- **문구 검사**: 자동 정규식이 다소 넓게 잡음(예: "완벽"이 "불완벽"에도). 1차 스크리닝이라 과탐이 미탐보다 낫다는 판단. 정밀 제어는 `pattern` 필드로.
- **MOQ 병목**: 부자재 MOQ만 계산(원료 MOQ 미반영).

## 5. 운영 팁

- **YAML 편집 → 새로고침**: Streamlit은 파일 mtime으로 캐시를 무효화합니다. 저장 후 브라우저 새로고침이면 반영.
- **로컬 전용**: 처방은 영업비밀입니다. **클라우드 배포 금지.** `uv run streamlit run streamlit_app.py`로 로컬에서만.
- **마이그레이션**: `python -m brandlab.migrate`는 원본을 `.bak`으로 백업합니다(gitignore됨).
- **한글 폰트**: 차트 한글이 깨지면 AppleGothic/NanumGothic 설치. 없으면 홈 화면에 경고가 뜸.

## 6. 다음에 만들 것 (그리고 지금은 만들지 말 것)

로드맵은 `플랫폼_고도화_규제레짐_프롬프트.md` 참고. **지금 실제로 필요한 것은 P9·P10·P11 뿐입니다.**

- **P9(레짐 추상화)** — ✅ 완료.
- **P10(화학제품안전법)** — ✅ 완료. 탈취제·방향제·초 지원. `data/regulatory/chemical_safety/fees.yaml`의 시험비는 KTR 공시 예시값 → 신고 전 실제 확인. `prohibited.yaml`·`restricted.yaml`는 **빈 껍데기라 직접 채워야** 하며, 비어 있으면 검사에서 "규제 데이터 미입력" 경고가 뜹니다(통과 아님).
- **P11(RegimeAdvisor)** — ✅ 완료. `brandlab advise`로 제품 의도(용도/기능/제형) → 레짐 후보·총 규제비용 비교·적합성 판정. **같은 향을 향수(화장품)로 낼지 디퓨저(방향제)로 낼지**를 비용으로 비교(SKU 10종 기준 270만원 차이). 매칭 규칙은 `data/regulatory/classification_rules.yaml`이며 **근사치 → 관할 기관 확인 필수**. 살균·살충·방충·기피 = REJECT(살생물제), 치약·손소독 = REJECT(의약외품).
- P12(포트폴리오)/P13(파이프라인)/P14(OEM)/P15(크로스체크)/P16(정리) — **그 단계에 실제로 도달했을 때** 만드세요.

> ⚠️ **도구 만들기가 일이 되는 함정**을 경계하세요. P9~P16을 다 하면 2~3주고, 그 사이 배합은 한 번도 안 돌아갑니다.
> 기준: **"이 기능이 없어서 지금 실제로 불편한가?"** 아니면 나중에.
