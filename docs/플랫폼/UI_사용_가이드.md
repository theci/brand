# 제품 개발 도구 사용 가이드 (화면판)

**터미널 없이 브라우저 화면만으로** 화장품·생활화학 제품을 기획하고 개발하는 도구입니다.
이 문서는 코딩을 몰라도 따라 할 수 있게, **실제 화면(사이드바 페이지)** 순서대로 설명합니다.

> ⚠️ 이 도구의 규제·라벨·효능 관련 결과는 **1차 스크리닝**이며 법적 판단이 아닙니다.
> 출시 전 반드시 식약처·환경부 고시 원문과 대조하고, 필요한 시험 성적서를 받으세요.

---

## 0. 실행하기 (5분)

### 처음 한 번만 (설치)
담당자가 대신 설치해 줬다면 이 단계는 건너뛰세요.
```bash
cd brand              # ★ 반드시 이 폴더 안에서
uv venv
uv pip install -e ".[dev]"
```

### 매번 실행
```bash
cd brand
uv run streamlit run streamlit_app.py
```
- 잠시 뒤 **브라우저가 자동으로 열립니다**(안 열리면 화면에 뜬 `http://localhost:8501` 주소를 복사해 브라우저에 붙여넣기).
- 끄려면 터미널에서 `Ctrl + C`.

> 💡 **자주 나는 오류 하나:** `ModuleNotFoundError: No module named 'brandlab'`
> → 명령을 **`brand` 폴더 밖에서** 실행했을 때 납니다. `cd brand` 후 다시 실행하세요.

## 1. 화면 구성

- **왼쪽 사이드바** = 페이지 목록. 클릭해서 이동합니다.
- **가운데** = 선택·입력·결과.
- 데이터(원료·처방 등)는 파일(YAML)에 저장됩니다. **파일을 고친 뒤에는 브라우저 새로고침(F5)** 하면 반영됩니다.

페이지는 크게 네 묶음입니다:

| 묶음 | 페이지 |
|---|---|
| 처방·제조·라벨·원가 | 처방 · 라벨 · 원가 |
| R&D 개발 루프 | 사전점검 · 버전비교 · 배치기록 · 실험 |
| 원료·재고·구매 | 원료 · 재고 · 장바구니 |
| 문서·규제·조향·문구 | 제품표준서 · 규제판정 · 조향 · 문구검사 |

## 2. 개발 순서대로 따라가기

제품 하나를 만드는 흐름 그대로 페이지를 안내합니다. **위에서 아래로** 진행하면 됩니다.

### STEP 1. 규제판정 — "내 제품은 무슨 법이고, 얼마 드나?"
가장 먼저 확인할 것. 같은 향 제품이라도 **향수(화장품)** 냐 **방향제(생활화학)** 냐에 따라 등록 비용이 수백만 원 차이 날 수 있습니다.
- **입력:** 용도(몸/공간/섬유/표면), 기능(향/세정/탈취/보습/살균), 제형(액상/고체/스프레이/지속방출), 예상 SKU 수, 검토 기간.
- **결과:** 가능한 법(레짐) 후보, **경로별 총 규제비용 비교표**(⭐가 최저비용), 적합성 판정(OK/주의/거절).
- **팁:** "살균·항균"을 기능에 넣으면 **살생물제**가 되어 승인에 1년 가까이 걸립니다(거절로 표시). 컨셉을 바꾸라는 신호예요.

### STEP 2. 원료 — 원료 등록·검색, 정보 자동채움
- **검색창**에 원료명·INCI·분류로 찾습니다. **붉은 행 = 성적서(CoA) 없음 또는 화장품용 아님** → 그대로 쓰면 안 됩니다.
- **🔎 PubChem 원료 자동채움:** 원료를 고르고 **[PubChem 조회]** 를 누르면 CAS 번호·밀도를 인터넷에서 찾아옵니다. **[채우기(저장)]** 를 누르면 비어 있던 칸만 채워집니다(기존 값·메모는 그대로).
- **팁:** 새 원료를 넣을 땐 이름·INCI만 적고 나머지는 이 버튼으로 채우면 편합니다.

### STEP 3. 처방 — 레시피를 배치 크기로 환산
- 처방을 고르고 **배치 크기(g)** 를 정하면, 원료별 넣을 양(g)이 상(A·B·C)별 표로 나옵니다.
- **배치 지시서(마크다운)를 내려받아** 인쇄하면, 그대로 보고 계량하며 만들 수 있습니다.

### STEP 4. 사전점검 — 만들기 **전에** 실패를 거른다
- **HLB 유화 균형:** 물+기름을 섞는 제품(로션·크림)에서 **층분리(기름 뜸)** 위험을 미리 봅니다. "적합"이면 안심, "위험"이면 유화제 조합을 바꾸라는 뜻.
- **배합한도:** 보존제 등이 법적 한도를 넘거나(초과) 딱 찼는지(도달) 표시합니다.
- **팁:** 비커에 원료 붓기 전에 꼭 확인하세요. 재료비 낭비를 막아줍니다.

### STEP 5. 배치기록 — 만든 뒤 실측을 남긴다
- **[새 기록지 생성]** 에서 처방·목표량을 고르면 기록지가 만들어집니다. **[저장]** 하거나 내려받으세요.
- 제조 후 저울·pH미터로 잰 **회수량·pH·관찰(묽음/분리 등)** 을 파일에 적습니다.
- **[기록 요약]** 탭에서 배치별 **수율·pH(정상범위 자동 판정)** 를 한눈에 봅니다.
- **팁:** "감으로 고치기"를 막는 핵심입니다. 다음 개선(STEP 6)의 근거가 됩니다.

### STEP 6. 버전비교 — 개선 전후를 비교
- 같은 제품의 **v1과 v2** 를 고르면 원료가 무엇이 늘고 줄고 새로 들어왔는지, **개당 원가가 얼마 바뀌었는지** 표로 보여줍니다.
- **팁:** "이 개선이 원가를 얼마 올렸나"를 숫자로 판단할 수 있습니다.

### STEP 7. 실험 — DOE·안정성
- **DOE:** 어떤 원료를 늘렸을 때 무엇이 좋아지는지 실험 결과를 그래프로 봅니다.
- **안정성:** 냉장/상온/45℃에 둔 시료의 관찰 일정과 밀린 관찰을 알려줍니다.

### STEP 8. 라벨 · 문구검사 — 표시와 광고
- **라벨:** 전성분 표시(안), 알러젠 표기 대상, 표시 의무 항목, 배합한도를 한 화면에.
- **문구검사:** 상세페이지 문구를 붙여넣으면 "미백·주름개선" 같은 **위험 표현을 색으로 강조**하고 대체안을 제시합니다.

### STEP 9. 원가 — 팔면 남나?
- 생산 수량·판매가를 넣으면 **개당 원가·공헌이익·손익분기 수량·MOQ 사장재고**와 판매가별 마진 곡선을 보여줍니다.

### STEP 10. 재고 · 장바구니 — 무엇을 얼마나 사나
- **재고:** 보유 원료와 유통기한을 **만료(🔴)/임박(🟡)/신선(🟢)** 으로 표시.
- **장바구니:** 생산 수량(또는 배치 g)을 넣으면 **재고를 빼고 부족한 만큼만** 공급사 판매단위로 올려 **구매 목록·예상 금액**을 만듭니다.

### STEP 11. 제품표준서 — 공장·기관 제출 문서
- 처방·전성분·제조지시·품질규격·규제·안정성·원가·배치이력을 **하나의 문서**로 만들어 **내려받습니다**(.md).
- **팁:** OEM 위탁제조사와 협의하거나 서류를 정리할 때 그대로 씁니다.

### (선택) 조향 — 향수·디퓨저를 만들 때
- 향 처방의 계량표, 노트(탑·미들·베이스) 비율, **IFRA 사용한도**를 확인하고, 숙성이 끝나 시향할 향을 알려줍니다.

## 4. 자주 묻는 것 (FAQ)

**Q. `ModuleNotFoundError: No module named 'brandlab'` 가 떠요.**
→ `brand` 폴더 밖에서 실행한 것입니다. `cd brand` 후 `uv run streamlit run streamlit_app.py`.

**Q. 값을 바꿨는데 화면이 그대로예요.**
→ 데이터 파일을 고친 뒤엔 **브라우저 새로고침(F5)** 하세요.

**Q. 차트의 한글이 깨져요.**
→ 한글 폰트(맑은 고딕·나눔고딕 등)를 설치하면 됩니다. 표·숫자는 영향 없습니다.

**Q. 내가 입력한 건 어디에 저장되나요?**
→ `data/`·`formulas/`·`experiments/` 폴더의 파일에 저장됩니다. 이 폴더를 백업하면 모든 데이터가 보존됩니다.

**Q. 인터넷이 꼭 필요한가요?**
→ 아니요. 딱 하나, **원료 자동채움(PubChem 조회)** 만 인터넷이 필요합니다. 나머지는 오프라인 동작.
