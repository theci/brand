## 0. 왜 이 사례인가
"산뜻 저자극 보습 로션"이라는 **컨셉이 처방으로 어떻게 구현되는지**를 보여주는 교과서적 예시.
성분 이름이 아니라 **설계 사상**을 읽는 훈련.

---

## 1. 교훈 ① — 전성분 순서를 곧이곧대로 믿지 마라

전성분은 함량 내림차순이지만 **1% 미만은 순서가 자유** → 브랜드는 마케팅 성분을 위로 올린다.

- **하이알루로닉애씨드가 목록 9번**이지만 실제 사용량은 **0.05~0.1%**. 스쿠알란(13번)보다 훨씬 아래여야 정상 → **"높아 보이게" 배치된 것.** 여기 속아 "HA 5%"로 넣으면 처방이 망가진다.
- 반대로 **유화제(폴리글리세릴·글리세릴스테아레이트)가 15·16번**으로 낮다. "지루한 구조 성분"을 뒤로 민 것. 오일을 유화하려면 실제론 더 상위 등급.

**→ 위치가 아니라 "기능 + 알려진 사용 수준"으로 재구성한다.**

## 3. 교훈 ② — 이 제품의 설계 사상 3가지 (진짜 배움)

1. **다이올 허들 방부** — 페녹시에탄올 대신 다이올(헥산다이올·펜틸렌·카프릴릴글라이콜)+에틸헥실글리세린을 겹쳐 방부. "무방부" 광고 가능 = **저자극 포지셔닝의 핵심 기술.**
2. **PEG-free·EDTA-free 순한 재료 선택** — 글루코오스 유래 유화제 + 소듐파이테이트. **성분이 곧 브랜드 메시지.**
3. **3중 점증 시스템** — 천연검(아이리쉬모스) + 냉공정 폴리머(Sepinov) + 카보머 → 묽지 않고 **산뜻하게 발리다 사라지는** 젤-로션 감촉.

> 배울 것은 성분명이 아니라 **"컨셉→처방 구현 방식"** 이다.

## 4. 실무자 방식 — 어떤 문서에 어떻게 계량·배합하나

현업 포뮬레이터는 **두 개의 문서**를 쓴다. 이 플랫폼이 그대로 구현한다.

### (1) 마스터 처방서 = 배합표 (Master Formula) — **진실의 원천**
- **단위: % w/w**(무게 백분율), **합계 항상 100.**
- 열: `상(Phase) | 원료(INCI/한글) | 기능 | % w/w`. 상(A수상/B유상/C냉각/D조정)으로 묶는다.
- 배치 크기와 무관하게 **비율만** 정의 → 재현성의 기준.
- **이 플랫폼에서는** → `formulas/<slug>/v<n>.yaml` 파일. 방금 만든 게 **`formulas/dokdo-clone/v1.yaml`** (사이드바 **처방** 페이지에서 열림).

### (2) 제조지시·기록서 = 배치 시트 (Batch/Manufacturing Record)
- 특정 배치 크기로 **% → g 환산** + 투입 순서·온도·교반·공정중점검(pH·외관·수율)·로트·서명.
- **이 플랫폼에서는** → **배치기록** 페이지가 처방을 배치 g으로 스케일하고 실측(수율·pH)을 남긴다.

**아래가 그 배치 시트다(100g 기준이라 % = g).** 실제로 이 표를 보고 계량한다:

**계량·배합 실무 규칙**
- **무게(g)로 계량**한다(부피 아님). 처방이 % w/w라 배치 g = %×(배치/100).
- **저울 두 대:** 대량(물·글리세린)은 0.01g, **<1% 성분(HA·잔탄·활성)은 0.001g** 정밀 저울.
- **상별로 미리 계량**해 비커에 모아두고(mise en place), A·B를 같은 온도(70~75℃)로 맞춘 뒤 유화.
- **투입 순서·온도가 문서의 핵심** — 열에 약한 활성/보존 다이올은 반드시 냉각 후(C).
- 배치마다 **로트·날짜·실측(수율·pH·외관)** 기록 → 재현성.

## 5. 홈랩 근사 재현 v1 (플랫폼 등록됨)

- 치환 논리: 마카다미아·폴리데센·호호바에스터 → **MCT+스쿠알란+다이메티콘** / 글루코오스 유화제 → **글리세릴스테아레이트시트레이트(올리브계)** / Sepinov·아이리쉬모스·카보머 → **잔탄검 1종**(첫 배치 단순화) / HA 3종 → **소듐하이알루로네이트**.
