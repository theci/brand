> **이 문서가 보여주는 것:** [제형 아키타입 지도](제형_아키타입_지도.md)와

## 0. 이번 주 그릇 — 왜 오일부터인가

아키타입 지도의 난이도 순서상 **오일(§7)이 입문 최적**이다. 무수(물 없음)라
유화·방부 문제가 없고, 골격이 가장 단순하다. "설계 감각"만 순수하게 연습할 수 있다.

## 1. 🖥️ d1 — 오일 아키타입 정독 (감각 프레임 3가지)

- **골격은 단순** — 에몰리언트 ~94% + 토코페롤 ~1% + EO 소량. (지도 §7)
- **올레인산 ↔ 리놀레산 스펙트럼** — 올레인산(동백·아르간·마카다미아)=리치·장벽 /
  리놀레산(로즈힙·햄프)=가볍고 빠른 흡수·산패 빠름. (팔레트 §2)
- **무게 조절이 설계의 전부** — 리치 베이스 + 경량 오일(스쿠알란·MCT)로 "리치하되 무겁지 않게".

## 2. 🖥️ d2 — 예시 3종에서 공통 골격 뽑기

기존 `face-oil`(호호바40+스쿠알란25+아몬드20+MCT13 / 토코페롤0.5+EO)과 데이터의
페이스·바디 오일 38종을 보면 공통 골격이 보인다:

```
베이스 오일 3~4종 (무게를 다르게 조합) ≈ 98~99%
 + 토코페롤 0.5~1%  (산패 방지, 필수)
 + EO 0.3~1%        (은은한 향, 선택)     → 합계 100
```

> **핵심 습관:** 예시를 외우지 말고 **골격(%대역)만 손으로 적는다.** 그러면 609개가 변주로 보인다.

## 3. 🖥️ d3 — 브랜드 변주 설계 (감각 → 처방)

브랜드 톤(**담백·정직·꾸밈없는·한국적**, 금지어: 럭셔리·프리미엄…)에 맞춰
**한국 서사 오일**로 골격을 채운다.

| 상 | 원료 | % | 왜 이걸 골랐나(감각·서사) |
|---|---|---|---|
| A | 동백오일 | 40 | 올레인산 리치·장벽. **한국 동백** = "직접·그대로" 서사 |
| A | 호호바오일 | 30 | 피지 유사·안정. 끈적임 없는 캐리어(무게 중간) |
| A | 스쿠알란 | 20 | **무게를 덜어** 산뜻하게(리치함 상쇄) |
| A | 오미자씨 오일 | 9.2 | **오미자** 항산화 = 차별 시그니처 |
| B | 토코페롤 | 0.5 | 산패 방지 |
| B | 네롤리 EO | 0.3 | 은은한 자연 향(꾸밈 최소) |

**설계 사상 3줄:** ① 리치 베이스(동백) + 경량(스쿠알란)으로 무게 균형 ②
안정성은 호호바가 담당 ③ 오미자로 브랜드 시그니처(향·claim이 아니라 오일 자체로).

```bash
# 처방 파일을 만들고(위 표대로 formulas/<slug>/v1.yaml) 검증
uv run python -c "from brandlab.core.models import Formula; import yaml; \
  Formula.model_validate(yaml.safe_load(open('formulas/camellia-schisandra-face-oil/v1.yaml')))"
```

### 3-1. 플랫폼 검증 — checks가 실수를 잡아준다 ✅

`사전점검(checks)` · `원가(cost)` 를 돌린 결과:

- ✅ **합계 100.00%**, 모델 검증 통과
- ⚠️→✅ **checks가 토코페롤 1.0% = 권장상한 '도달'을 경고** → 0.5%로 낮추고
  그 0.5%를 오미자로 이동. **이게 플랫폼을 쓰는 이유** — 감각으로 그린 처방의
  실수를 코드가 잡아준다.
- ✅ **유수분 밸런스**: oil 100%, 텍스처 "밤/무수 근접", 에몰리언트 99.2% → "무난한 범위"
- ✅ **방부**: 무수라 보존제 불필요, 산패만 관리(토코페롤로 OK)
- 💰 **원가**: 개당 **1,698원**(원료 798 + 드로퍼 900, 30ml·100개).
  ⚠️ 두 가지 배움: (1) 동백·오미자·네롤리 **단가 미입력 → 과소추정**(실제 소싱가 입력 필요),
  (2) 드로퍼 **MOQ 3,000개** → 100개만 쓰면 **사장 재고 2,900개(260만원 묶임)**.
  초기엔 소량 MOQ 부자재부터.

## 4. 🧪 l1 — 실물 제조 + 사용감 일지 (손으로 하는 유일한 단계)

데이터로 못 배우는 **촉감·향**을 몸으로 익히는 단계. 소량(30~50g)으로.

**제조 순서**
1. A상 4종을 % 비율로 정밀 계량(50g 배치 → 동백20 / 호호바15 / 스쿠알란10 / 오미자4.6g)
2. 상온에서 맑게 저어 균일화(가온 불필요)
3. B상(토코페롤0.25 / 네롤리0.15g) 넣고 마저 저음
4. 드로퍼 병 충전 + 라벨(제조일·전성분)

**사용감 일지** (`빠른 시험 로그` 페이지 활용):

| 시점 | 발림성 | 흡수속도 | 잔여 유분막 | 향(강도/호감) | 광 | 자극 |
|---|---|---|---|---|---|---|
| 도포 직후 | /5 | | | | | |
| 5분 후 | | /5 | /5 | | | |
| 30분 후 | | | /5 | | /5 | |

> **핵심 질문:** "리치하되 무겁지 않게" 목표대로인가? 무거우면 스쿠알란↑/동백↓,
> 너무 가벼우면 반대로. **이 관찰이 v2의 근거**가 된다. 감각 → 처방 → 감각의 순환.

## 5. 이 루프를 복제하는 법

이번 주는 오일이었다. 다음 주부터 같은 4단계를 다른 아키타입에 반복한다:

1. **d1 정독** — 그 아키타입 지도 절 + 팔레트 해당 기능군 카드
2. **d2 골격** — 예시 3종에서 %대역만 손으로 추출
3. **d3 설계** — 브랜드 변주 1종을 `formulas/`에 + checks/cost
4. **l1 제조** — 소량 + 사용감 일지 → 다음 버전 근거

제형 마스터리 페이지(`pages/33`)가 **이번 주 할 것을 자동으로 짚어준다.**
8주면 주요 그릇이 손에 익는다 — all-knowing이 아니라 **"한 브랜드를 자신있게 개발할 팔레트"**.
