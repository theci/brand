## 🎯 이 루틴의 3원칙

1. **두 축을 매주 동시에.** 🧪 제품(STEP 진행) + 📣 마케팅(브랜딩·콘텐츠·팬). 하나만 하면 실패.
2. **빠른 루프 = 성취감.** 제품도 콘텐츠도 "빨리 여러 개 → 즉시 판정 → 접거나 남기고 → 기록". ([RnD 사이클](../홈랩/빠른반복_RnD_사이클.md) 구조를 그대로.)
3. **플랫폼이 곧 작업대.** 매 STEP은 특정 페이지에서 값을 넣고 **저장→F5**로 확인. `오늘·진행` 트래커가 매일의 다음 퀘스트를 짚어줍니다.

```
빠른 루프(당일/주간)              느린 루프(백그라운드, 몇 주)
제품: 처방 변형·즉시판정          제품: 안정성 8주(Week4에 걸어두면 알아서 익음)
마케팅: 포스트·훅 즉시반응        마케팅: 팬·후기·대기자 축적
```

> 💡 **두 축을 잇는 한 줄:** 주말 랩에서 **만드는 과정을 촬영**하면 그게 한 주 콘텐츠 원본이 됩니다. 한 번 일하고 두 축을 먹여요.

### 하루의 형태 (직장 병행)
| 유형 | 언제 | 시간 | 하는 일 |
|---|---|---|---|
| 🖥️ 데스크 | 평일 저녁 | 20~40분 | 플랫폼에 값 입력·기록 **또는** 콘텐츠 1개 제작 |

| 📣 소통 | 매일 | 5~10분 | 소유 채널·DM·댓글 응대 |

```
📣 마케팅:

```

## W1 — STEP 0 기획 = 제품과 마케팅의 공통 뿌리
> **핵심 통찰:** STEP0의 **브랜드 코어**는 제품 방향이자 **마케팅의 뿌리**입니다. 두 축이 여기서 하나로 만납니다.

**🧪 제품 (플랫폼 STEP0)**
- [ ] [데스크] `페르소나·JTBD` — `dry-office-30s`(냉난방 사무실 30대) + 페인 2줄 입력 → 저장·F5 → **🔥 페인 우선순위**("오후 당김" 1위) 확인.
- [ ] [데스크] `시장·경쟁 조사` — 출처 1 + 경쟁 A사(gaps: 끈적임·흡수 느림) 입력.
- [ ] [데스크] `문제 정의` — **[✨ 자동 초안]** → "끈적여서 덧바를 수 없음"으로 다듬기.
- [ ] [데스크] `포지셔닝` — [기획에서 프리필] → 신물질(다축 보습)·수치(오후 4시 당김 개선) 채워 **포지셔닝 문장** 확정.

**📣 마케팅 (같은 STEP0 데이터로 브랜드 코어)**
- [ ] [데스크] `브랜드 코어` 9칸 — 오후(OHU)/약속("산뜻하게, 오후까지")/톤(담백·정직)/금지어(완벽·최고·미백)/컬러(EAE0D5·6B705C·C97C5D). ([가이드 1-2 + 부록A](../출시/브랜딩_마케팅_완전가이드.md))
- [ ] [데스크] `브랜딩 느낌 미리보기` — 컬러 스와치·무드보드 프롬프트로 톤 확인.
- [ ] [📣] 빌드인퍼블릭: "우리 브랜드가 푸는 문제 = 오후 당김" 포스트. + 매일 소통 5분.

**🏅 산출물:** 포지셔닝 문장 · 브랜드 코어 9칸(=마케팅 메시지 뿌리).

## W2 — STEP 1~2 규제·원료·포장·재고
**🧪 제품**
- [ ] [데스크] `규제판정` — 화장품/적합 확인.
- [ ] [데스크] `원료(도감)` — 핵심 원료 PubChem 자동채움, 배합한도 확인.
- [ ] [데스크] `포장재` — jar-50ml(MOQ 3000) 등록 → **사장재고 리스크 인지**.
- [ ] [데스크] `재고` — 만료/임박/신선 상태 확인.

**📣 마케팅 (신뢰 브랜딩)**
- [ ] [📣] **성분 투명성 콘텐츠** — "왜 이 원료를 골랐나"(기술 오너십 = 대부분 못 하는 것). [이미지 프롬프트 '원료 페트리' 장면 레시피] 활용.
- [ ] [📣] keeper 포맷 찾기: 성분 카드 vs 랩 브이로그 vs 텍스트 — 반응 즉시 확인.

**🏅 산출물:** 규제 OK · 원료/포장 확정 · 신뢰 콘텐츠 2편.

## W3 — STEP 3 처방·사전점검 5중 + 첫 랩
**🧪 제품**
- [ ] [데스크] `처방` — A수상/B유상/C냉각, % 합계 100 입력(v1).
- [ ] [데스크] `사전점검` — **5중(HLB·배합한도·상용성·보존·유수분)** 한 화면 판정. 유상 13% "로션" 확인.
- [ ] [랩] **첫 배치 100~200g** 제조 → 유화·pH·사용감 즉시판정. **과정 촬영.**

**📣 마케팅**
- [ ] [📣] "비커 붓기 전에 5가지를 자동 점검한다" — **전문성/신뢰** 콘텐츠(랩 촬영 원본 활용).
- [ ] [📣] 랩 원본 1개 → 3조각으로 발행. 매일 소통.

**🏅 산출물:** 처방 v1 · 5중 통과 스크린샷 · 첫 배치 기록.

## W4 — STEP 4~5 제조·기록 + DOE 빠른 루프 + 안정성 착수(느린 루프)
**🧪 제품 (빠른 루프의 핵심 주)**
- [ ] [데스크] `실험·DOE` — 유화제/오일/점증제 2³ 설계.
- [ ] [랩] **한 세션 3~6변형** 제조·채점 → 주효과 확인(오일↑=흡수↓·백탁↑ → 산뜻 목표엔 유상↓). keeper만 남김.
- [ ] [랩] `배치 기록` — 수율·pH 실측. **안정성 시료 RT/45℃ 배치**(느린 루프 8주 시작).

**📣 마케팅**
- [ ] [📣] "여러 배합을 한 번에 비교하는 법(DOE)" 과정 공개 — 빌드인퍼블릭 정점.
- [ ] [📣] "접은 것도 데이터" 서사(실패=진행). 조회수 말고 **저장·댓글** 확인.

**🏅 산출물:** DOE 주효과 · 배치기록 · **안정성 시료 착수(달력에 8주 표시)**.
