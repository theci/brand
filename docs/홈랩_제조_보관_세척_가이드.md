# 홈랩 제조·보관·세척 실무 가이드 — 왕초보편

> **누구를 위한 문서인가**
> "저울에 유산지 까는 걸 방금 알았다" 수준의 1인 창업 초보가, 집에서
> **로션(에멀전) 시제품을 직접 만들고·소분하고·세척·보관**하는 실무를 손에 익히는 문서.
> 장비를 무엇을 살지는 [홈랩 장비구축 가이드](홈랩_장비구축_가이드.md)를 먼저 보세요.
>
> **대전제(플랫폼 철학과 동일):** 집은 **R&D(처방 개발·시제품·테스트) 전용**입니다.
> 집에서 만든 화장품을 파는 것은 대부분 불법 — 처방을 완성하면 **OEM/ODM 공장으로 이관**해 생산·판매합니다.
> 이 문서의 온도·%·시간은 **일반 관행 예시**이며, 원료별 세부는 **공급처 TDS/CoA**로 확인하세요.

## 0. 큰 그림 — 로션 만들기 한 장 요약

```
[소독] → [계량: 상 나눠서] → [수상A·유상B 따로 가열 70~75℃·20분 유지]
   → [온도 맞춰 합치고 = 유화(강하게 교반!)] → [식히며 계속 교반]
   → [40℃ 이하서 냉각첨가C: 보존제·향·활성] → [pH 확인·조정] → [소분·기록]
```

핵심 3가지만 기억: **① 상을 나눈다 ② 온도를 맞춰 합친다 ③ 유화 순간엔 세게 젓는다.**

---

## 1. 시작 전 위생 — 제조의 8할은 소독

물이 든 화장품은 **미생물이 반드시 번식**합니다. 보존제만 믿지 말고 **깨끗하게 시작**하세요.

- 손 씻고, 작업대를 **70% 에탄올**(또는 70% IPA)로 닦는다.
- 비커·스패출러·교반기 날·소분 용기를 **70% 알코올로 소독 후 자연 건조**.
- 머리 묶기, 가능하면 니트릴 장갑. 재채기·기침 방향은 작업대 반대로.
- 화장품 도구는 **주방과 분리**(식품과 교차 금지).

> 💡 **왜 70%?** 순수 알코올(≈100%)보다 **70%가 살균력이 더 좋아요**(세포막 통과·건조 지연). 물 탄 알코올이 오히려 정답.

## 2. 계량(칭량) — 정확함이 재현성을 만든다

처방은 **%**로 되어 있어요. 배치 총량을 정하면 각 원료 g = **% × (총량/100)**.
예) 200g 배치에서 글리세린 5% = **10g**. (즉 200g이면 % 숫자에 2를 곱하면 g)

**계량 꿀팁 (왕초보용)**
- **유산지/칭량지(또는 약포지)를 깔고 → 영점(TARE) → 원료를 담는다.** 비커 안 더럽히고 옮기기 쉬움. (방금 배운 그거, 맞아요!)
- **점성·액체 원료**(글리세린·오일)는 유산지 대신 **담을 비커째 저울에 올리고 TARE 후 바로 부어** 넣는다(유산지에 눌어붙어 손실 방지).
- **소량 원료(활성·향·보존제·검)** 는 **0.01g 정밀 저울**로. 0.1% 원료를 부엌 저울로 재면 오차가 처방을 망칩니다.
- **덜 때는 깨끗한 스패출러**로, 통에 손·젖은 도구 넣지 않기(오염).
- 흘리면 **닦고 다시** — 누적 오차가 유화·pH를 흔든다.
- **파우더가 정전기로 튀면** 유산지를 반 접어 'V자 도랑'을 만들어 부으면 덜 날린다.
- 저울은 **수평·바람 없는 곳**에 두고, 켠 뒤 잠깐 안정된 후 사용.
- **물은 마지막에 100%를 맞추는 값**(잔량)으로 계산 — 다른 걸 다 더하고 남는 만큼 물.

## 3. 제조 A to Z — 단계별 상세 + 노하우

### ① 상 나눠 계량
- **수상 A**: 정제수 + 글리세린·판테놀 등 휴멕턴트 + 검(잔탄 등).
- **유상 B**: 오일 + 버터 + 지방알코올(세틸 등) + **유화제**.
- **냉각첨가 C**: 보존제 + 향 + 열에 약한 활성 → **아직 넣지 않고 대기**.

> 💡 **검(잔탄·카보머 등)은 물에 바로 넣으면 '피시아이'(덩어리)가 생겨요.** **글리세린에 먼저 개어(선분산)** 놓았다가 물에 풀면 매끈해집니다.

### ② 각 상 가열 — 70~75℃, 20분 유지
- A, B를 **각각** 중탕(냄비에 물, 그 안에 비커)이나 핫플레이트로 70~75℃까지.
- **중탕이 초보에 안전**(국소 과열 적음). 냄비 물이 비커에 튀지 않게.
- **온도계로 확인**(감으로 X). 두 상에 하나씩 있으면 편하고, 없으면 번갈아 잰다.
- **왁스·지방알코올·유화제가 완전히 녹을 때까지** + 70~75℃에서 **약 20분 유지**(완전 용해 + 미생물 부담↓).

> 💡 **물 증발 보정:** 오래 가열하면 수상 물이 날아가 %가 틀어져요. **시계접시/뚜껑을 덮어** 증발을 줄이고, 합치기 직전 **줄어든 무게만큼 뜨거운 정제수를 보충**하면 정확합니다.

### ③ 합쳐서 유화 — 여기가 승부처 (강한 교반!)
- **두 상 온도를 ±5℃로 맞춘 뒤** 합친다(보통 **유상 B를 수상 A에** 부음).
- **합치는 순간부터 2~5분간 고속으로** 세게 섞는다 → **미니 호모지나이저/핸드블렌더/미니 거품기**.
- 손 젓기·마그네틱 바만으로는 **전단력이 부족**해 분리되기 쉽다. 유화 순간만큼은 고전단.

> 💡 **온도가 어긋나면(예: 한쪽 60℃, 한쪽 75℃) 유화가 잘 안 붙어요.** 합치기 전 반드시 온도 맞추기. 마요네즈 만들 때 기름을 한 번에 안 붓는 것과 같은 이치.

### ④ 식히며 계속 교반
- 유화 직후엔 고속, 이후엔 **저속으로 바꿔 식는 동안에도** 저어준다(굳으며 분리 방지).
- **기포**가 많이 생겼으면 **저속으로 낮추고 잔열에 잠시 방치**하면 빠진다. (과교반은 기포·점도 저하)

### ⑤ 40℃ 이하서 냉각첨가 C
- **40℃ 아래로 식은 뒤** 보존제(페녹시에탄올 등)·향·열에 약한 활성 투입.
- 뜨거울 때 넣으면 **보존제·향이 날아가거나 변질**됩니다.

### ⑥ pH 확인·미세조정
- **30℃대~실온**에서 pH 측정(로션 목표 대략 5 안팎, 처방·활성에 따라).
- 높으면 **시트릭/락틱애씨드 희석액을 아주 소량씩** 떨어뜨려 조정(한 방울씩, 다시 측정).
- pH 미터가 정확(교정 필요), 스트립은 참고용.

> 💡 **소량 배치라도 최소 100g 권장.** 너무 적으면 균질기 날이 안 잠겨 유화가 안 돼요. 개발 비교는 100~200g가 편합니다.

## 4. 원료별 투입 노하우 (자주 쓰는 것)

| 원료/유형 | 노하우 |
|---|---|
| **잔탄검·검류** | 글리세린에 **선분산** 후 수상에 (피시아이 방지) |
| **카보머** | 물에 분산 → 부풀린 뒤 **중화제(TEA/아르기닌 등)로 중화**해야 젤이 됨 |
| **히알루론산(가루)** | 물에 조금씩 뿌려 **하루 불려** 완전히 녹은 뒤 사용 |
| **보존제(페녹시 등)** | **냉각(40℃↓) 후** 투입 |
| **에센셜오일·향** | 맨 마지막 냉각 단계, 소량. 리브온은 보수적으로 |
| **파우더 활성(나이아신 등)** | 수상에 **미리 용해**, 덩어리 없이 |
| **비타민C·레티놀** | 열·빛·pH에 약함 → **냉각 후·저pH/무수 설계·불투명 용기** |
| **오일·버터** | 유상에서 가열 용해. 산패 취약 오일은 **냉각 단계**에 넣기도 |

## 6. 안정성 시험 실무 — 소분·조건·관찰

만든 로션을 **여러 조건에 나눠 두고** 시간에 따라 안 무너지는지 본다.

**소분**
- **투명 유리 바이알**에 소분(분리·변색·기포를 눈으로 봐야 함).
- 조건당 **~15~20g**면 충분(100g이면 4조건 나눠도 남음).
- **실제 판매 용기**에도 하나 담아 용기 적합성 확인.
- **라벨**: 배치명·조건·제조일 (예: `daily-lotion v2 / 45℃ / 09-06`).

**조건 (4개 + 대조군)**

| 조건 | 어디에 | 무엇을 본다 |
|---|---|---|
| **45℃ 고온(가속)** | 인큐베이터/발효기 | 분리·변색·악취·pH 이동 빨리 확인 |
| **실온(RT)** | 직사광 없는 서랍 = **대조군** | 실제 유통 근사 |
| **4℃ 저온** | 냉장고 | 결정화·굳음·탁도 |
| **동결–융해** | 냉동고 ↔ 실온 **24h씩 3~5회** | 유화 견고성(얼렸다 녹여 분리?) |

**관찰 주기·항목**
- **1·2·4·8주**에 관찰 → `실험 · 안정성` 페이지에 입력.
- 항목: **외관·분리·색·냄새·경도·pH**. RT 대조군과 비교.
- 45℃에서 분리·악취·pH 급변 = **경고 신호**(상온에서도 언젠가 터짐).

> ⚠️ 홈 안정성은 **개발 스크리닝**용이지 공식 성적서가 아니에요. 출시용은 OEM/시험기관.

## 7. 세척·소독 — 순서가 있다

1. **먼저 닦는다** — 기름·왁스는 키친타월로 훔쳐냄. **오일·왁스를 하수구에 붓지 말 것**(막힘·환경).
2. **온수 + 주방세제**로 세척, 충분히 헹굼(왁스·유화제는 뜨거운 물이 잘 빠짐).
3. **소독** — **70% 알코올**로 헹구거나 분무 후 **자연 건조**.
4. **제조 전에도** 도구·용기를 알코올 소독하고 시작.
5. 균질기 **날**은 분해 세척(에멀전이 끼기 쉬움), 완전 건조.
6. 화장품 전용 도구는 **주방과 분리 보관**.

## 8. 원료 보관 — "냉장고에 다"는 틀렸다

원료마다 최적이 달라요. 다 냉장하면 **결로·결정화** 문제가 납니다.

| 보관 | 대상 |
|---|---|
| **냉장(4~13℃)** | 산화 취약 오일(로즈힙·달맞이꽃·포도씨), 천연 추출물, **불안정 활성(비타민C·레티놀·펩타이드)**, 개봉한 취약 오일 |
| **실온 냉암소**(서늘·그늘·차광) | 대부분 — 안정 오일(MCT·호호바)·버터·왁스·글리세린·계면활성제·검류·보존제·pH조절제 |
| **실온 + 습기 차단** | **분말류**(나이아신·SCI·검) — 냉장고 습기·결로에 굳음. 밀봉 + 실리카겔 |
| **서늘·밀봉·차광** | 에센셜오일·에탄올(**인화성**) — 갈색병, 화기 피함 |

**공통 원칙**
- **밀봉**(공기·습기 차단), **차광**(갈색/불투명), 직사광·열원 피함.
- **라벨**: 원료명·로트·수령일·개봉일·사용기한. **선입선출(FIFO)**.
- **오염 방지**: 깨끗한 스패출러로 덜어 쓰고 손·젖은 도구 넣지 않기.
- **냉장 보관품은 개봉 전 실온으로** 되돌려 **결로 방지**(찬 병 바로 열면 물맺힘 → 산패·오염).

## 9. 기구 다루기·유지

- **저울(0.01g)**: 수평·무풍, 정기 영점·교정 추. 소량 활성의 생명줄.
- **pH 미터**: 사용 전 **표준액으로 교정**, 프로브는 **보관액에** 담가 보관(마르면 망가짐).
- **온도계**: 인큐베이터·냉장·냉동의 **실제 온도 검증**용으로도 하나.
- **가열**: 중탕 권장, 핫플레이트는 **직화 아님**. 빈 비커 공가열 금지.
- **균질기**: 사용 후 즉시 분해 세척·건조(굳은 에멀전 제거).
- **위험 원료**: 가성소다(비누)=보호안경·장갑·환기, 산=주의, 파우더=분진 마스크.

---

## 10. 폐기·안전

- 실패 제형·유분은 **굳혀서/닦아서 일반쓰레기**. 하수구 지양.
- 인화성(에탄올·EO)은 화기 멀리, 밀봉. 환기.
- **소량 원칙** — 실패해도 손실·위험이 작다.

**제조 전**
- ☐ 작업대·도구·용기 70% 알코올 소독
- ☐ 처방 %→g 환산표, 유산지·스패출러·저울(0.01g)·온도계 준비
- ☐ 상(A/B/C) 나눠 계량, C는 대기

**제조 중**
- ☐ A·B 각각 70~75℃, 20분 유지 (물 증발분 보충)
- ☐ 온도 ±5℃ 맞춰 합치고 **2~5분 고속 유화**
- ☐ 식히며 저속 교반, 기포 빼기
- ☐ 40℃↓에서 C(보존제·향·활성) 투입
- ☐ 실온에서 pH 확인·미세조정

**제조 후**
- ☐ 배치기록(STEP4)에 수율·pH·관찰 실측 입력
- ☐ 안정성용 소분(투명 바이알·라벨·4조건+대조군)
- ☐ 도구 닦고 세척·소독·건조
